## What this file is

This is a compressed reference substrate distilled from an 18-file marketing-theory corpus (encyclopedic taxonomies of marketing knowledge, psychology, intelligence, objectives, strategy, channels, formats, technology, operations, measurement, and optimization). It gives the Marketing Strategist Agent a **mental-model vocabulary and lookup reference** — the concepts, hierarchies, distinctions, and principles a seasoned marketing strategist keeps in their head.

**How to use it:**
- Treat this as background knowledge you *reason with*, not a workflow you *execute*. There is no branching logic here to "run."
- Use the **Core tier** for foundational reasoning: the knowledge hierarchy, persuasion mechanisms, intelligence framework, and objective chains that should shape how you think about any marketing problem.
- Use the **Reference tier** as a dictionary/index: dip into a specific entry (channels, formats, tactics, technology, operations, measurement, optimization, strategy, research, logic types, models) when a task touches that domain, to recall the right vocabulary, distinctions, and taxonomy rather than inventing ad hoc terms.
- When a task requires *doing* something (extracting a brand voice, building a psychographic profile, running a campaign build), call the appropriate **Skill** — this KB supplies the concepts that inform that execution, it does not replace it.

# CORE TIER

The core tier is organized using the corpus's own six-dimension index (from *Marketing Intelligence.md*): **Formats, Models, Intelligences, Logics, Knowledge, Strategies**. Each core file's substance is folded into the dimension it belongs to, with Marketing Knowledge and Marketing Psychology given the most depth since they are the deepest, most reusable substrate.

## 0. The master hierarchy (from Marketing Knowledge)

Everything below sits inside one causal chain. Keep this in mind as the spine of all marketing reasoning:

**KNOWLEDGE → INTELLIGENCE → LOGIC → MODEL → STRATEGY → EXECUTION → MEASUREMENT → LEARNING** (loops back into KNOWLEDGE)

- **Knowledge**: structured understanding of a domain ("premium skincare buyers evaluate ingredients, efficacy, reviews").
- **Intelligence**: what you derive from knowledge to answer a specific decision question ("for this audience, ingredient transparency will outperform celebrity endorsement").
- **Logic**: the reasoning applied to compare options against criteria.
- **Model**: the repeatable structural mechanism used to decide/act.
- **Strategy**: the chosen direction.
- **Execution**: the concrete campaign/asset/channel activity.
- **Measurement**: what happened.
- **Learning**: what should update the knowledge base.

Marketing Knowledge itself decomposes into **10 domains**: Customer, Product, Market, Psychological, Communication, Media, Technology, Commercial, Cultural, Regulatory — each with a base question (who buys / what's sold / competitive environment / why people behave / how meaning-persuasion is built / where-when attention is bought / what enables execution / how it connects to money / how social context changes meaning / what's legally permitted). These are not independent lists but a graph: e.g., creative format draws on Communication Knowledge, placement on Media Knowledge, targeting on Customer Knowledge, buying on Commercial/Media Knowledge, optimization on Technology/Commercial Knowledge, compliance on Regulatory Knowledge.

**12 governing principles worth internalizing:** evidence before assumption; context before generalization; customer before channel; causality before correlation; granularity must match the decision; knowledge must be relational (a fact is more valuable connected to products/behavior/media/economics/outcomes); time matters (knowledge expires); uncertainty must be represented (known → probable → inferred → hypothesized → unknown); constraints (legal/commercial/tech/cultural) are knowledge too; knowledge should produce decisions; every outcome creates new knowledge; knowledge should remain traceable to evidence.

### The 10 knowledge domains, one level deeper

| Domain | Covers | Notable sub-structure |
|---|---|---|
| **Customer** | identity, needs, behavior, journey, segmentation, value, feedback | Need hierarchy: Problem → Need → Desired outcome → Solution requirement. Segmentation bases: demographic, geographic, psychographic, behavioral, transactional, value-based, need-based, intent-based, lifecycle-based, contextual. Value stack: CAC, CLV, AOV, purchase frequency, retention, churn, margin contribution, payback period. |
| **Product** | identity, attributes, benefits, positioning, lifecycle, product-market fit | Attribute types: functional, technical, performance, physical, economic, experiential, symbolic. Positioning stack: category position, USP, differentiators, points of parity/difference, reasons to believe, brand/product promise. |
| **Market** | structure, competitors, demand, dynamics, opportunity | Structure: market/category/subcategory/segment/niche/price tier. Competitive knowledge spans direct/indirect/substitute/emerging competitors × their pricing/positioning/messaging/distribution/media activity. |
| **Psychological** | motivation, perception, cognition, decision, persuasion | *(fully expanded in §1 below — this is the deepest domain)* |
| **Communication** | message, creative, narrative, brand voice, adaptation | Narrative structures: problem→solution, before→after, hero journey, demonstration, testimonial, comparison. A single proposition needs different versions across Audience × Stage × Context × Channel × Format × Device. |
| **Media** | channel, format, placement, targeting, buying, optimization | See Reference tier: Formats, Channels, Technologies. |
| **Technology** | martech stack, data, tracking, AI, measurement tech | See Reference tier: Technologies. |
| **Commercial** | pricing, revenue, sales, distribution, promotion | Pricing mechanisms: list, discount, subscription, bundling, tiering, dynamic, premium, penetration, freemium. |

### Useful sub-chains to reuse in reasoning:
- Benefit hierarchy: Feature → Functional benefit → Emotional benefit → Social benefit → Customer outcome.
- Customer journey: Awareness → Discovery → Consideration → Evaluation → Purchase → Onboarding → Usage → Retention → Expansion → Advocacy.
- Product lifecycle: Development → Launch → Growth → Maturity → Decline → Renewal.
- Execution dependency chain: Campaign → Channel → Inventory → Placement → Ad Unit → Format → Creative → Audience/Targeting → Buying → Optimization → Outcome.

## 1. Knowledge dimension — Marketing Psychology (the persuasion/cognition substrate)

This is the highest-value content in the corpus — preserve real substance here. Formal model: **Behavior = f(Person, Context, Stimulus, State, Memory, Social Environment, Friction)**; for marketing specifically, **Outcome = f(Targeting, Message, Creative, Placement, Offer, Experience, Timing)**, with psychology as the mechanism connecting the two. A more complete master equation from the corpus: **Person × State × Context × Mechanism × Stimulus × Format × Placement × Target × Buying Mechanism × Decision Stage → Behavior → Measurement → Experiment → Learning → Optimization.** Don't model psychology as a flat list ("scarcity, social proof, emotion, FOMO...") — model it as this multidimensional system, because the same mechanism (e.g. scarcity) routes through completely different formats/placements/targeting depending on context.

### The psychological pipeline (where interventions enter)
TARGET PERSON → PSYCHOLOGICAL STATE → ATTENTION → PERCEPTION → INTERPRETATION → COGNITIVE PROCESSING → EMOTION → MOTIVATION → EVALUATION → DECISION → ACTION → EXPERIENCE → MEMORY → LEARNING → REPEAT BEHAVIOR → ADVOCACY/LOYALTY/DEFECTION.

A headline hits attention; a visual hits perception; framing hits interpretation; a benefit hits motivation; a testimonial hits social proof/trust; a price anchor hits comparative evaluation; a CTA hits action initiation; onboarding hits learning/habit formation.

### 15 psychological domains and their mechanisms

| Domain | Core question | Key mechanisms | Marketing levers |
|---|---|---|---|
| **Attention** | What gets noticed? | selective attention, salience, novelty, contrast, pattern interruption, curiosity, expectation violation | hooks, thumbnails, first-3-seconds, scroll-stopping, subject lines |
| **Perception** | What's perceived? | gestalt principles (proximity, similarity, closure), perceptual fluency, cognitive ease, sensory congruence | visual identity, layout, typography, color, packaging |
| **Cognitive** | How is info processed? | heuristics, schemas, categorization, prototypes, associative thinking, mental accounting; biases (anchoring, availability, representativeness, confirmation, status quo, loss aversion, optimism, omission, endowment, peak-end, primacy/recency) — treat these as components of decision architecture, not isolated "hacks" | message simplification, choice architecture, pricing architecture, information hierarchy, benefit framing, objection reduction, cognitive-load reduction |
| **Behavioral** | What produces behavior? | cue → behavior → reward → reinforcement loop; conditioning | loyalty programs, streaks, gamification, reminders |
| **Emotional** | What moves feeling? | happiness, excitement, fear, anxiety, relief, surprise, anger, sadness, pride, belonging, nostalgia, aspiration, envy, admiration, disgust, trust, hope; intensity (low "that's nice" vs high "I must share this"); direction (approach/avoidance/conflicted) | storytelling, emotional branding, brand personality, crisis communication, cause-related marketing, experiential marketing |
| **Motivational** | What creates desire/action? | approach motives (gain, status, mastery, belonging) vs avoidance motives (loss, risk, regret, effort avoidance); need structures (functional/emotional/social/identity/security/autonomy/competence) | urgency, incentive framing, benefit stacking |
| **Decision** | How are choices made? | Need→Recognition→Search→Consideration→Comparison→Evaluation→Choice→Purchase; heuristics, risk perception, choice overload, default effects | product comparison design, recommendation engines, bundling, checkout design |
| **Persuasion** | How does belief/preference change? | authority, social proof, reciprocity, commitment/consistency, liking, scarcity, unity, argument quality, framing (gain vs loss) | testimonials, evidence, comparisons, guarantees |
| **Social** | How do others influence? | conformity, reference groups, in/out-group, status signaling, social comparison | reviews, ratings, influencer/expert endorsement, community — ask "who does this person compare themselves with?" not just "who is this person?" |
| **Identity** | How does self influence consumption? | actual/ideal/ought self, aspirational identity, role/group/status identity, identity signaling | positioning, lifestyle branding, premium/luxury cues, tribal brands |
| **Memory & Learning** | What's remembered? | encoding/retrieval, distinctive cues, emotional memory, primacy/recency | distinctive brand assets, slogans, repetition, mnemonic devices |
| **Habit & Retention** | What makes behavior recur? | Trigger → Routine → Reward → Repetition → Automaticity | subscriptions, replenishment reminders, streaks |
| **Trust & Relationship** | Why believe/stay? | Credibility + Predictability + Benevolence + Evidence = Trust | guarantees, certifications, transparent pricing, case studies |
| **Context & Environment** | How does situation change behavior? | Behavior = f(Person × Situation), not f(Person) alone; time, device, mood, crowding, competing stimuli | contextual advertising, dayparting, situational offers |
| **Experimentation & Optimization** | Which mechanism works under which conditions? | independent vars (message, framing, emotion, proof, price, CTA) × moderators (audience, intent, category, context) → dependent vars (attention, conversion, retention) | controlled testing infrastructure |

### 17 governing principles
Relevance (influence scales with goal-relevance); Attention (nothing works unless noticed); Cognitive economy (prefer lower mental effort); Context (same stimulus, different context, different behavior); Individual differences; Motivation (needs desire+ability+opportunity); Perceived value (not objective value); Uncertainty reduction increases confidence; Social influence; Consistency (repeated coherent signals strengthen association); Feedback (behavior changes future state); Learning (repetition modifies future response); Friction (every extra step can kill action); Choice architecture; Reinforcement; **Credibility** (mechanisms lose power when perceived as manipulative); Measurement (hypotheses must connect to observable behavior).

### Psychological targeting is richer than demographic targeting
Layer these together rather than picking one: **identity** (age/occupation/lifestyle/cultural identity), **behavioral** (purchase/browsing/frequency/recency), **intent** (informational/comparison/purchase/renewal/problem-solving), **psychological** (motivations, attitudes, values, risk tolerance, novelty-seeking, status orientation, price sensitivity, goal orientation), **contextual** (time/location/device/current activity). The strongest targeting model is usually **who + what they want + what state they're in + what context they're in** — not any single dimension alone.

### Transaction structure changes the psychology, not just the economics
One-time purchase, subscription, recurring, installment/financing, freemium, free trial, membership, and bundle each create a *different* psychological dynamic on top of the same product: free trial lowers perceived risk; subscription reduces repeated-decision cost; bundling changes the perceived-value comparison; installments change perceived immediate cost; freemium reduces entry friction. When recommending a commercial structure, name the psychological effect it's meant to produce, not just the pricing mechanic.

### Identity as a purchase mechanism, not just a targeting variable
People often buy a version of themselves, not a product. A luxury watch traces Timekeeping → Luxury → Status → Identity signal → Social meaning — the functional benefit (telling time) is nearly irrelevant to the actual purchase driver. When identity is the operative mechanism, self-concept sub-types matter: actual self, ideal self, ought self, aspirational identity, role identity, group identity, status identity, identity signaling, self-expression, identity protection (the last being why people resist messaging that threatens a valued self-image rather than simply ignoring it).

### Psychological outputs form a ladder, not a flat metric list
Distinguish which level a requested outcome actually sits at before picking a lever: **Psychological outputs** (attention, awareness, perception, comprehension, emotion, motivation, belief, trust, preference, intention) sit upstream of **Behavioral outputs** (click, engagement, search, inquiry, purchase, usage, repeat purchase, referral, sharing), which sit upstream of **Commercial outputs** (conversion rate, AOV, revenue, CLV, retention, churn, CAC efficiency, profitability) and **Brand outputs** (awareness, salience, associations, consideration, preference, loyalty, advocacy). A campaign optimized purely for a commercial output while ignoring the psychological output it depends on (e.g. maximizing clicks without building trust) will show short-term lift and long-term erosion — check that the psychological output the mechanism is supposed to produce is actually moving, not just the commercial number three steps downstream.

### One mechanism traced end-to-end (the reusable pattern)
Take **scarcity**: psychological mechanism (perceived limited availability) → cognitive effect (urgency) → emotional effect (FOMO) → motivational effect (act sooner) → creative format (countdown, badge) → placement (product page, checkout, email) → targeting (high-intent, cart abandoners) → buying mechanism (limited inventory framing) → behavior (faster decision) → optimization (intensity, timing, wording, audience). The same trace pattern applies to social proof, authority, urgency, etc. — **the psychological mechanism is never the same thing as the marketing asset used to express it.** Keep that distinction; it prevents sloppy reasoning ("we used a testimonial" ≠ "we activated trust").

## 2. Intelligences dimension — Customer Intelligence, Market/Brand/Performance/AI-era Intelligence (deduped)

*MARKETING INTELLIGENCES.md* and *Marketing Intelligence Systems.md* are ~70% overlapping — merged below into one framework. Two organizing views exist and both are useful:

**View A — by subject (5 families):**
1. **Customer Intelligence** — Identity, Behavioral, Attitudinal, Need & Intent, Journey, Segmentation, Value, Retention, Relationship. Answers: who, doing what, wanting what, why, what next, what to do about it. Behavior tends to be weighted over declared preference.
2. **Market Intelligence** — Structure (TAM/SAM/SOM, concentration), Demand, Competitor, Category, Trend, Pricing, Distribution, Media, Opportunity/Threat.
3. **Brand Intelligence** — Awareness, Perception, Positioning, Association, Reputation, Distinctiveness, Creative, Cultural, Equity. (Different from Performance Intelligence: "CTR dropped" is performance; "why is the brand becoming less relevant to this audience" is brand.)
4. **Performance Intelligence** — Campaign, Channel, Media, Creative Performance, Conversion, Attribution, Incrementality, Budget, Experimentation, Forecasting. Key discipline: **attribution ≠ incrementality** — correlation is not causation; a converting audience may have converted anyway.
5. **AI-era Intelligence** — Predictive, Prescriptive (not just "73% purchase probability" but "show Customer X Product A via Channel B within 24h"), Generative, Agentic (observe→diagnose→generate alternatives→simulate→act→measure→adjust), Real-Time, Autonomous Optimization, Synthetic Audience (simulation tool, not a replacement for real validation), Simulation, AI Search/Discovery Intelligence (what does an AI assistant know/recommend about the brand — distinct from SEO), Machine-Mediated Customer Intelligence (the buyer may delegate research/purchase to an agent), Human-AI Collaborative Intelligence (AI: computation/pattern-recognition/prediction/generation/optimization; Human: context/judgment/strategy/taste/ethics/accountability).

**View B — by intelligence maturity (applies within any subject family):**
Data (Level 0, no intelligence yet) → **Descriptive** ("what happened") → **Diagnostic** ("why") → **Predictive** ("what's likely") → **Prescriptive** ("what should we do") → **Generative** ("what should we create") → **Autonomous** (detect→predict→decide→execute→observe→learn, closed loop). A mature system needs to move up this ladder, not just build dashboards.

**Full-system pipeline:** DATA → IDENTITY → SIGNAL → KNOWLEDGE → INTELLIGENCE → DECISION → OPTIMIZATION → ACTIVATION (media/CRM/site/commerce) → MEASUREMENT → LEARNING → back to DATA.

**10 core principles:** intelligence must lead to a decision (no orphan insights); context beats isolated metrics; behavior beats assumption; correlation ≠ causation; intelligence must be temporal (state+history+trajectory+context, not a static profile); intelligence must be probabilistic ("72% predicted probability," not "will buy"); intelligence must connect across families; must operate at multiple granularities (market→category→brand→campaign→channel→placement→unit→audience→individual); must operate across time horizons (historical/current/predictive/simulated); AI should close the loop (observe→reason→act→measure→learn), not just produce an insight.

**The deepest reduction:** every intelligence problem = **Entity → State → Signal → Decision → Outcome → Learning**. Use this five-question frame (who/what are we reasoning about; what's its current state; what evidence signals change; what action follows; did it improve the objective) as a fast diagnostic on any intelligence request.

**Relationship matrix — how each intelligence family answers the same seven execution questions differently:**

| Intelligence family | Targeting | Creative | Format | Placement | Buying | Optimization |
|---|---|---|---|---|---|---|
| Customer | who | what message | which format | where | how much | how to improve |
| Market | which market | category message | market format | market environment | market inventory | market allocation |
| Brand | who should perceive the brand | brand expression | brand format | brand context | reach/quality | brand lift |
| Performance | highest-value audience | highest-performing creative | best-performing format | best-performing placement | efficient acquisition | ROI/incrementality |
| AI-era | predicted audience | generated/personalized creative | dynamic format | dynamic placement | autonomous buying | autonomous optimization |

**Time horizons per family** (useful for deciding which intelligence to lean on for a given decision): Customer intelligence spans immediate→lifetime; Market intelligence weeks→years; Brand intelligence months→years; Performance intelligence minutes→months; AI-era intelligence real-time→future simulation. A mature system holds all five simultaneously (now → today → this week → this quarter → this year → long-term) rather than defaulting to whichever dashboard is open.

**Customer Intelligence sub-map** (the deepest of the five families, worth knowing at this resolution): Identity Intelligence (who — identity resolution, household/account graphs), Behavioral Intelligence (what they do — clickstream, purchase sequence, propensity scoring; usually weighted over declared preference), Attitudinal Intelligence (what they think/feel — sentiment, objection, unmet-need discovery), Need & Intent Intelligence (informational/navigational/commercial/transactional/comparison/renewal/switching/advocacy intent), Journey Intelligence (entry/exit points, loops, friction, channel-switching, journey anomalies — real journeys are not linear funnels), Segmentation Intelligence (dynamic, micro-, predictive, propensity, lookalike, exclusion segmentation), Value Intelligence (CAC, LTV, CLV, ARPU, value tier), Retention Intelligence (churn/inactivity/downgrade prediction plus "why leaving" and "which intervention has highest retention probability"), Relationship Intelligence (loyalty, trust, advocacy, community participation).

## 3. Logics dimension — the objective chain (from Marketing Objectives)

Marketing objectives are **not** the same as campaign objectives, and they are **not** the same as the mechanisms used to pursue them. Keep three things separate:
- **OBJECTIVE** — what do we want to change (e.g., increase qualified customer acquisition).
- **MECHANISM** — how we'll attempt it (audience targeting + search + video + retargeting + offer + landing page + bid optimization).
- **RESULT** — what actually changed (+37% qualified customers, -12% CAC).

"Video," "carousel," "retargeting," "CPM," "A/B testing" are **mechanism/execution-taxonomy items, never objectives.**

### The causal chain
BUSINESS OUTCOME → MARKETING OBJECTIVE → CUSTOMER/BEHAVIOR OBJECTIVE → COMMUNICATION OBJECTIVE → CAMPAIGN OBJECTIVE → PLATFORM OBJECTIVE → EXECUTION MECHANISMS → MEASUREMENT → OPTIMIZATION. If this chain breaks (e.g., you can't trace a campaign objective back to a business outcome), the objective is probably poorly defined.

### 8 objective families
1. **Market** — creation, expansion, penetration, development, share, competitive displacement.
2. **Brand** — awareness → recall → familiarity → salience → association → consideration → preference → intent → purchase (a causal ladder — don't judge a salience campaign on sales alone).
3. **Demand** — problem awareness → category demand → interest → intent → **demand capture**. Distinguish **demand creation** (no active demand → build awareness → problem recognition → desire → intent; content/video/influencer/PR territory) from **demand capture** (existing demand → detect intent → present solution → remove friction → convert; search-advertising territory).
4. **Acquisition** — reach → traffic → leads → qualified leads → opportunities → users → customers → profitable customers. More leads ≠ better if conversion quality collapses; the real objective is usually *qualified* customer acquisition.
5. **Conversion** — click → enquiry → registration → trial → purchase → AOV/revenue.
6. **Customer value** — activation → adoption → repeat purchase → cross-sell → upsell → retention → reactivation → CLV.
7. **Relationship** — engagement → loyalty → community → advocacy → referral → UGC (creates a flywheel: Awareness→Consideration→Purchase→Retention→Advocacy→Referral→new prospects, not just a linear funnel).
8. **Economic/efficiency** — revenue, profit, CAC, CPL, CPA, ROAS, ROI, payback, LTV:CAC, incrementality.

### Five objective directions (what's being changed)
A. Change the number of people (reach/awareness/acquisition). B. Change what people think (perception/trust/positioning/preference). C. Change what people do (visit/engage/purchase/repurchase/refer). D. Change relationship value (AOV/frequency/CLV/retention). E. Change the economics (CAC/CPL/ROAS/ROI).

An objective = TARGET + DESIRED CHANGE + BEHAVIOR/PERCEPTION + TIME + MAGNITUDE + ECONOMIC CONSTRAINT. "Increase qualified customers from segment X by 25% in 6 months while keeping CAC below ₹2,500" is an objective. "Run Facebook ads" is not.

### 12 principles
Objective before mechanism; one primary objective per campaign; objectives need a measurable state change (not "improve brand" but "unaided awareness 32%→42%"); need a target population; need a time horizon (SMART-style); optimize the real business outcome, not a proxy metric; distinguish leading (reach, engagement, leads, intent) vs lagging (customers, revenue, retention, CLV) indicators; match objective to customer state; match objective to controllability; measure incrementality where possible; optimize the bottleneck (if awareness is fine but consideration is weak, more reach makes the problem bigger); objectives should form an unbroken causal chain to the business result.

### Objective → primary measurement mapping (use to sanity-check any campaign brief)

| Objective | Primary measurement | Secondary measurements |
|---|---|---|
| Awareness | aided/unaided awareness | reach, frequency, recall |
| Reach | unique reach | frequency, CPM |
| Salience | mental availability | branded search, recall |
| Consideration | consideration rate | engagement, branded search |
| Lead generation | qualified leads | CPL, conversion rate |
| Customer acquisition | new customers | CAC, conversion rate |
| Sales | revenue | orders, AOV |
| Profitability | contribution profit | CAC, margin, ROAS |
| Retention | retained customers | churn, repeat rate |
| Loyalty | repeat behavior | frequency, CLV |
| Advocacy | referrals/advocacy | NPS, UGC, referral rate |
| Market share | category share | penetration, competitive switching |

The governing rule: **the objective determines the KPI — the KPI should never determine the objective** (a common organizational failure mode is optimizing whatever is easiest to measure rather than what was actually meant).

### Objectives form a many-to-many graph, not a tree
The same objective is reachable through multiple mechanisms, and the same mechanism serves multiple objectives — e.g. video can serve awareness, education, consideration, lead generation, conversion, retention, *and* advocacy; retargeting can serve consideration, conversion, reactivation, *and* retention. Never assume a 1:1 mapping between a channel/format and an objective.

## MARKETING FORMATS
**What it covers:** the structural packaging of a marketing message. Formula: **Format = Object × Placement × Audience × Buying × Creative × Delivery Logic × Optimization** — e.g. "Instagram Ad" decomposes to Sponsored Content → Social Feed → Video Unit → Interest/Behavior Audience → Auction → Vertical Video Creative → Conversion Objective → Algorithmic Optimization.

| Format family | Examples |
|---|---|
| Display | banner, interstitial, rich media, carousel, roadblock |
| Text/Native | search text, sponsored listing, advertorial, recommendation unit |
| Video | in/out-stream, pre/mid/post-roll, bumper, shoppable, CTV |
| Audio | spot, host-read, dynamic insertion, podcast sponsorship |
| Commerce | sponsored product/brand, shopping ad, livestream commerce |
| Interactive | poll, quiz, calculator, AR/VR, configurator |
| Conversational | click-to-message, WhatsApp commerce, chatbot campaign |
| Experiential | activation, sampling, immersive/projection |
| Physical/direct | direct mail, catalog, package insert |

**Non-obvious distinctions:** Channel ≠ Format ≠ Unit ≠ Placement (e.g. Social → Instagram Feed [placement] → Carousel [format] → Sponsored product card [unit]). Treat a format as a tuple **F = (Object, Placement, Targeting, Buying, Creative, Delivery, Optimization)** rather than a fixed catalog entry — there is no honest fixed count of "marketing formats," only combinable primitives.

**Delivery/decision logic (often skipped, decides *why this person got this message now*):** rule-based (IF audience=X AND context=Y THEN creative A), sequential (exposure 1→2→3→conversion), trigger-based (search/visit/cart/location/time/weather/content trigger), algorithmic (predicted CTR/CVR/engagement/value/LTV drives selection), adaptive (system continuously changes audience/bid/creative/placement/frequency/timing/budget based on observed performance).

**Optimization-technique taxonomy specific to formats:** creative optimization (headline/image/video/CTA/offer/hook/format testing), audience optimization (segment expansion/suppression, lookalike expansion, retargeting refinement, exclusion), bid optimization (manual, target CPA/ROAS, max conversions/value), placement optimization (expansion/exclusion, inventory quality, device/geo/time optimization), budget optimization (allocation, pacing, spend acceleration/throttling), conversion optimization (click→lead→purchase→revenue→LTV→incrementality, in ascending sophistication), experimentation (A/B, multivariate, holdout, geo, lift studies, bandits).

## MARKETING CHANNELS
**What it covers:** distribution/communication environments, classified first by ownership.

- **Owned** (website, app, email/CRM, community, store) — control + accumulated first-party data.
- **Paid** (search, social, display, video, TV, retail media, influencer, sponsorship) — you compete for scarce inventory access.
- **Earned** (PR, reviews, organic mentions, search rankings) — optimization target is *probability of propagation*, not "buy more."
- **Shared** (communities, creator ecosystems, co-marketing) — jointly shaped by brand + platform + audience.

Each channel decomposes into: Subchannel → Environment → Format → Placement → Targeting → Data source → Buying → Pricing → Creative mechanism → Delivery → Optimization → Measurement → Attribution. **Do not store "Facebook Ads" as an atomic unit** — store the full attribute set, because a single product can run simultaneously across Paid Social (auction/CPM/purchase-optimized), Search (CPC/high-intent-query), Email (owned/revenue-optimized), and Retail Media (auction/shopper-intent) with fundamentally different mechanics.

**12 principles:** audience–channel fit; intent–channel fit (search = explicit intent, social = discovery, email = known relationship); context–message fit; format–attention fit; placement economics; audience quality > audience size; **attributed ≠ incremental**; optimize marginal returns, not current ROAS; frequency has diminishing returns; channels interact (don't over-credit last touch); measurement must match mechanism (don't judge an awareness channel by last-click sales); optimization changes channel behavior (a machine-optimized channel ≠ the same channel manually targeted).

**Per-channel-family cheat sheet:**

| Channel family | Distinguishing mechanic | Sub-channels worth naming |
|---|---|---|
| Search | the query itself is a targeting signal; keyword/intent auction | organic, paid, shopping, local, maps, app-store, voice/AI search |
| Social | platform ≠ placement — feed/stories/reels/explore/marketplace/messaging are each distinct | feed, stories, reels/short video, live, groups/communities, creator ecosystem |
| Display | programmatic ecosystem with page-position taxonomy (above/below fold, header, in-content, interstitial) | open exchange, private marketplace, preferred deal, programmatic guaranteed |
| Video | a format family spanning many environments, not one channel | pre/mid/post-roll, in-stream/out-stream, CTV, FAST channels |
| Email | combines channel + owned audience database + automation engine | acquisition, newsletter, promotional, transactional-adjacent, lifecycle, triggered |
| Commerce/Retail media | media exposure + commerce intent + transaction data sit close together | sponsored product/brand, retail search, digital shelf, in-store screen |
| Affiliate/Partner | distribution → attributable action → commission (not impression-buying) | publisher, coupon, cashback, comparison, referral |
| Influencer/Creator | hybrid of earned-looking creative + paid distribution + measurable conversion | celebrity/macro/mid/micro/nano/employee/customer creator tiers |
| Human | interaction itself is the delivery mechanism | sales, tele-sales, account management, field marketing, brand ambassadors |
| Product | the product surface distributes marketing | packaging, onboarding, in-product recommendation, referral prompts |

**A single execution is a full attribute bundle, not a channel name** — e.g. Paid Social × Short-form video × Mobile feed × 9:16 format × Reels placement × Retargeting+purchase-propensity targeting × UGC dynamic creative × Auction/CPM buying × Purchase-conversion optimization × Controlled frequency × Incremental-ROAS measurement. Store/reason about channels at this resolution, never as a single label.

## MARKETING TACTICS
**What it covers:** the composable, executable layer. **Tactic = Objective × Audience × Message × Offer × Channel × Placement × Unit × Buying × Timing × Optimization × Measurement** — a tactic is a fully specified tuple, not a name ("retargeting" isn't a tactic; "retarget cart-abandoners with a dynamic product ad, mobile+web+app placement, auction/CPA buying, 1–7 day window, controlled frequency" is).

**12 tactical layers:** Market & Audience, Offer & Value (pricing/discounts/bundling/risk-reversal), Message & Positioning, Creative, Channel, Placement, Distribution & Delivery (owned/paid/earned/shared), Buying & Transaction, Conversion, Lifecycle & Relationship, Optimization, Measurement & Control.

**Five distinctions to keep straight:** Strategy ≠ tactic; Channel ≠ placement; Format ≠ creative; Targeting ≠ audience (audience = who, e.g. cart-abandoners; targeting mechanism = how you reach them, e.g. first-party behavioral retargeting); Buying ≠ optimization (buying = CPC auction; optimization = maximize qualified leads).

**Audience-tactic sub-taxonomy** (worth knowing cold): demographic, geographic, firmographic (B2B), behavioral, interest, intent, lifecycle (unknown→prospect→engaged→high-intent→customer→repeat→VIP→churn-risk→lapsed), first-party, lookalike/modeled, contextual, **exclusion** (often overlooked — targeting = inclusion + exclusion + prioritization).

**Message-tactic mechanisms by appeal type:** functional (save money/time, improve performance), emotional (excitement, pride, belonging, aspiration, security, status), social (popularity, authority, community, identity), rational (specs, comparisons, evidence, demonstrations, guarantees), competitive (better/faster/cheaper/safer/easier/more premium), urgency (limited time/inventory, deadline), scarcity (limited quantity, exclusive access).

**Offer-tactic mechanisms:** price incentives (percentage/fixed discount, coupon, introductory price), transaction incentives (free shipping/installation/consultation, free trial, BOGO), bundling, risk reversal (guarantee, free returns, cancellation, trial period), access (early/exclusive/members-only), financing (installments, deferred payment). The offer changes the *economics* of the decision, distinct from the message which changes the *interpretation* of it.

**The 35 primitive dimensions** the corpus proposes as the true atomic taxonomy of a tactic (more durable than any named "tactic list" since platforms/tactics churn but these primitives don't): Objective, Audience, Segment, Targeting, Exclusion, Message, Angle, Offer, Incentive, Creative, Format, Placement, Unit, Channel, Distribution, Device, Environment, Buying method, Pricing model, Bid method, Budget method, Timing, Trigger, Frequency, Sequence, Funnel stage, Conversion mechanism, Sales mechanism, Retention mechanism, Optimization method, Experimentation method, Attribution method, KPI, Control rule, Feedback loop. A fully specified tactic instantiates a value for each relevant primitive — e.g. cart-abandonment retargeting: Objective=conversion, Audience=cart abandoners, Segment=high-intent, Targeting=first-party behavioral, Exclusion=purchasers, Message=product reminder, Offer=optional discount, Creative=dynamic product, Format=display/native, Placement=mobile feed+web+app, Channel=paid digital, Buying=auction, Timing=1–7 days post-abandonment, Frequency=controlled, KPI=CPA/ROAS/revenue.

## MARKETING TECHNOLOGIES
**What it covers:** the infrastructure stack, best understood as 14 domains connected by one loop: DATA → IDENTITY → AUDIENCE → DECISIONING → CHANNEL → PLACEMENT → CREATIVE → DELIVERY → EXPERIENCE → CONVERSION → MEASUREMENT → ATTRIBUTION → OPTIMIZATION → LEARNING → back to DATA.

Domains: Data, Identity & Audience, Marketing Automation, Advertising & Media, Creative & Content, Experience & Conversion, Commerce & Revenue, Analytics & Intelligence, Experimentation & Optimization, Measurement & Attribution, Communication & Engagement, Privacy/Consent/Governance, Infrastructure & Integration, AI & Autonomous Marketing.

**Scale reality check:** there is no authoritative count of "marketing technologies" because the category is open-ended — but a useful taxonomy-level model is: ~14 technology domains → 70–100 technology families → 250–400 capability classes → 1,000+ feature types → 3,000+ individual tasks/actions → 100+ distinct algorithms/decision mechanisms → 200+ data objects → thousands of interfaces/integrations. The point isn't the exact number — it's that "technology" is never the atomic unit. A single "technology" like a DSP contains dozens of chained mechanisms (Programmatic Advertising → Demand-Side Platform → Campaign Management → Audience Targeting → Lookalike Audience → Model Construction → Feature Engineering → Similarity Scoring → Bid Decision → Auction → Creative Selection → Impression → Conversion Measurement → Optimization).

**A. Data technologies — collection and management, concretely:**
- *Collection surfaces:* website tracking, app tracking, server-side tracking, pixel tracking, SDK tracking, event tracking, conversion tracking, form tracking, call tracking, CRM data capture, transaction/POS data, email and social interaction data, search behavior, advertising interaction, product interaction, customer-service interaction, offline event ingestion, IoT/device signals.
- *Atomic collection tasks:* capture event → timestamp → identify user/device → attach metadata → validate → deduplicate → enrich → store → forward → trigger action.
- *Management pipeline:* Raw Data → Cleaning → Normalization → Transformation → Enrichment → Storage → Activation, running through data warehouses, data lakes, customer databases, CDPs, marketing databases, ETL/ELT pipelines, event streams, data catalogs, and data-quality systems. The underlying question any data technology must answer: *what happened, to whom, when, where, through which channel, under what context, and what should happen next?*

**B. Identity technologies:** resolve the hierarchy Person → Customer → Account → Household → Device → Browser → Session → Event via first-party identity, login state, customer/device IDs, cookie identity, mobile advertising IDs, hashed identifiers, household identity, identity graphs, and cross-device resolution. Core functions: identify, match, resolve, merge, separate, persist, authenticate, anonymize, pseudonymize. This layer is where privacy/consent constraints bind hardest — identity technology cannot be treated as simply "tracking users" once consent-aware identity and hashed/pseudonymized identifiers become the default.

**C. Audience technologies** turn data+identity into actionable groups across 15 audience types (demographic, geographic, firmographic, psychographic, behavioral, contextual, transactional, intent, engagement, lifecycle, predictive, lookalike, similarity, account-based, custom), operated on via: create, define, include, exclude, segment, score, rank, predict, expand, suppress, refresh, sync, activate, measure. Industry taxonomies (e.g. IAB's Audience Taxonomy) exist specifically to standardize this vocabulary across platforms.

**D–E. Advertising & media technology, at placement/unit resolution (the area with the richest combinatorics):**
- *Channel families with named sub-channels:* Search (paid search, shopping, local, maps, retail search, app search); Display (web, in-app, programmatic, direct, native); Social (feed, stories, reels/short video, messaging, social search, creator placements); Video (online, CTV, OTT, streaming, in-stream, out-stream, pre/mid/post-roll); Audio (streaming audio, podcasts, digital radio, programmatic audio); Retail media (sponsored product/brand/display, retail search, retail onsite/offsite); Digital out-of-home (billboards, street furniture, transit, airports, retail/place-based screens).
- *Placement dimensions* (channel ≠ placement — e.g. Social → Instagram → Feed → Mobile feed placement → Carousel ad unit; or CTV → Streaming service → Content stream → Ad pod → 15-second video): Environment (web/app/mobile/desktop/TV/streaming/physical screen/email/messaging/search results), Position (above/below fold, header, sidebar, footer, in-feed, in-content, interstitial, overlay, end screen), Context (editorial/search/commerce/social/entertainment/transactional/utility/messaging), Device (smartphone/tablet/desktop/CTV/smart TV/console/digital signage).
- *Ad unit taxonomy by family:* Display (banner, leaderboard, medium/large rectangle, skyscraper, billboard, interstitial, expandable, floating, sticky, rich media); Native (in-feed native, recommendation widget, sponsored article/listing, promoted content, native video); Video (linear, non-linear, companion, interactive, shoppable — standardized technically via VAST for ad-metadata/tracking delivery to players); Social (single image, carousel, collection, story, short video, lead form, poll, interactive unit); Search (text ad, product listing, shopping unit, local ad, app promotion); Audio (audio spot, companion banner, interactive audio); CTV (video spot, interactive CTV, pause ad, overlay, shoppable CTV, sponsored content, ad pod position).
- *Targeting mechanisms, one level deeper than the Core Tier list:* Geographic (country/region/city/postal code/radius/geo-fence/location history), Demographic (age/gender/household/income/education), Behavioral (browsing/search/engagement/purchase/content consumption/app usage), Contextual (content category, keywords, topic, genre, page semantics, video metadata, product category, brand-safety classification — asking "what is the person consuming right now" rather than "who is the person," standardized via taxonomies like IAB's Content Taxonomy for both contextual targeting and brand safety).
- *Buying mechanisms, named:* Direct (advertiser↔publisher), Programmatic (advertiser/DSP → exchange/SSP → publisher), Open Auction (multiple buyers compete per impression), Private Marketplace (restricted auction, selected buyers), Preferred Deal (preferential access without full commitment), Automated Guaranteed/Reservation (inventory reserved under agreed conditions) — the technical language enabling impression-level automated transactions at scale is OpenRTB.
- *Auction-time bid logic:* impression available → bid request → eligibility filters → audience evaluation → context evaluation → campaign eligibility → bid calculation → creative eligibility → auction → winner → ad delivery → measurement. The bid calculation itself weighs Expected conversion value × Probability of conversion × Business value × Audience value × Context value × Predicted quality, minus constraints (budget, frequency, brand suitability, bid floor, inventory quality, audience/creative restrictions, supply-path rules). Loss reasons in real systems are explicit and standardized: below-floor bid, lost to higher bid, creative filtered, category exclusion, supply-chain restriction.

**F. Creative technology** is a decision system, not design software — it answers *what message should this person see, in what format, under what circumstances?* Hierarchy: Asset → Format → Message → Variant → Personalization → Dynamic Elements → Template → Rendering → Assembly → Delivery. Named technologies: digital asset management, creative management platforms, dynamic creative optimization (DCO), template engines, personalization engines, feed-based creative, product feeds, creative versioning, automated resizing, video/image/copy generation, creative testing and scoring. **DCO concretely:** instead of 1 audience → 1 creative, the system composes Audience + Context + Product + Location + Behavior + Time + Device + Historical performance → creative decision → variant — e.g. returning visitor + running-shoe product + Mumbai + rainy weather + previous product view → system selects "Rain-ready running shoes." This is a decision engine, not merely a creative tool.

**G. Experience & commerce technology:** the post-click layer — website personalization, landing-page builders, CMS, recommendation engines, on-site search/merchandising, on-site messaging (popups, forms, chat, conversational interfaces), progressive profiling, dynamic content, experimentation — running the loop Traffic → Identify → Understand intent → Select experience → Deliver experience → Observe behavior → Optimize. Commerce technology (product information management, product feeds, catalog management, shopping ads, product discovery, search merchandising, promotions/coupons, cart/checkout, subscription, loyalty, referral, affiliate systems) centers on the data object Product + Customer + Intent + Inventory + Price + Context.

**H–J. Analytics, measurement & attribution technology:** analytics moves through Descriptive (traffic/revenue/CTR/conversion/CAC/ROAS/retention) → Diagnostic (segment/funnel/cohort/path/attribution analysis, performance decomposition) → Predictive (conversion/churn/LTV prediction, demand forecasting, lead scoring, purchase propensity) → Prescriptive (increase budget, change audience/bid/creative/offer/channel allocation). Measurement and attribution technology must be kept distinct: measurement asks *what happened* (impression, click, engagement, conversion, revenue, viewability, brand lift, incrementality, reach, frequency measurement technologies); attribution asks *what caused or contributed to it* (last-click, first-click, linear, position-based, time-decay, data-driven/algorithmic, multi-touch, media-mix, incrementality models).

**I. Optimization technology, by technique family:** rule-based (IF CPA > target THEN reduce bid), threshold-based (IF ROAS < 2 THEN decrease spend), mathematical optimization (maximize conversions subject to budget+frequency+inventory constraints), statistical (regression, Bayesian models, confidence intervals, probability models), machine learning (classification, regression, ranking, clustering, recommendation, propensity models), sequential (Observe→Predict→Act→Observe→Update), and reinforcement learning (State→Action→Reward→Policy update) — this last family is where marketing technology starts becoming genuinely intelligent rather than merely automated. Experimentation technology names the same rigor for testing: A/B, multivariate, split, holdout, geo, incrementality, creative, audience, offer, pricing, landing-page, and channel experiments, run through Hypothesis→Treatment→Control→Randomization→Measurement→Statistical inference→Decision.

**K. Communication technology** spans email, SMS, push, WhatsApp/messaging, in-app, web notifications, voice, chat, conversational AI, and direct mail — each with its own delivery system, audience system, frequency logic, personalization, trigger logic, creative format, measurement, and optimization; these are not interchangeable just because they're all "channels."

**L. Privacy, consent & governance technology** is not an optional compliance add-on — it directly changes what the rest of the stack can do: consent management, preference management, privacy management, data governance, data lineage, data access controls, data retention, identity protection, clean rooms, secure data collaboration, first-party data systems. In programmatic advertising specifically, supply-chain transparency mechanisms (ads.txt, sellers.json, SupplyChain object and related standards) exist to establish authorized sellers and transparency across the transaction chain.

**M. Integration technology** is the actual nervous system connecting everything else: APIs, webhooks, SDKs, pixels, server-to-server connections, ETL/ELT, CDP connectors, data-warehouse connectors, CRM connectors, ad-platform connectors, identity synchronization, audience synchronization — e.g. CRM → CDP → Audience → DSP → Ad → Website → Conversion → Analytics → back to CRM. Marketing technology becomes useful only when systems in this chain actually communicate; a best-in-class point solution with no integration path is worth less than a mediocre one that's fully wired in.

**N. AI & autonomous marketing technology**, by function: AI for *understanding* (classification, sentiment analysis, topic/intent detection, customer summarization), for *prediction* (conversion probability, churn, LTV, purchase propensity, lead quality, demand), for *generation* (copy, images, video, audio, creative variants, landing pages, campaign concepts), for *decisioning* (audience selection, bid selection, budget allocation, creative selection, offer selection, next-best-action), and *AI agents* running the loop Goal→Research→Plan→Execute→Observe→Evaluate→Learn→Replan — a fundamentally different architecture from traditional rule-based automation because the system replans rather than just re-executing the same rule.

**Objects vs. mechanisms vs. constraints vs. outputs** (a cleaner mental model than a vendor list): Objects = customer, audience, product, campaign, creative, impression, conversion. Mechanisms = identify, segment, target, bid, personalize, deliver, measure, attribute, optimize, automate. Constraints = budget, privacy/consent, frequency, brand safety, bid floor. Outputs = audience, bid, creative, experience, prediction, attribution result. Building a durable taxonomy from "what data → who → what intent → where → how bought → what creative → how delivered → how measured → how learned" outlasts any specific vendor category (CRM/CDP/DSP/DMP labels churn constantly).

**Identity hierarchy** underlying all targeting/personalization tech: Person → Customer → Account → Household → Device → Browser → Session → Event, resolved via first-party identity, login state, hashed identifiers, identity graphs, and cross-device resolution — constrained increasingly by privacy/consent rules, so "identity technology" cannot be treated as simply "tracking users."

**The technology relationship matrix** (a second way to slot any specific tool/capability, complementary to the 14-domain list): Data (what do we know?) → Identity (who/what generated it?) → Audience (who should be included/excluded?) → Context (what environment are they in?) → Channel (where do we communicate?) → Placement (where exactly does it appear?) → Unit (what occupies the placement?) → Buying (how is inventory acquired?) → Creative (what is shown?) → Decisioning (which option is selected?) → Delivery (how does it reach the user?) → Experience (what happens after exposure/click?) → Measurement (what happened?) → Attribution (what contributed to it?) → Optimization (what should change?) → Automation (can the change happen automatically?) → AI (can the system reason/predict/generate?) → Governance (what is allowed?) → Integration (how does it connect to everything else?). Any vendor tool can be located by answering these 19 questions rather than by its product category label.

**The technology flywheel** — the same loop the domain list opens with, now with the decision layer made explicit: Business Objective → Marketing Objective → Data Signals → Identity → Audience → Decision Engine → (splits into Channel / Offer / Message, then Placement / Price / Creative) → Buying Mechanism → Auction → Ad Delivery → Experience → Behavior → Conversion → (splits into Measurement and Revenue) → Attribution → Optimization → Learning → back to Data. Reasoning about a new technology request means locating which node(s) of this loop it actually touches, rather than treating it as a standalone feature ask.

**14 governing principles** (compressed): better signals → better decisions; the system needs an appropriate identity representation for its target entity; context changes intent for the same person; relevance increases message-situation match probability; timing changes the value of an action; every optimization has constraints; every action should generate feedback; unmeasured actions can't be reliably optimized; correlation ≠ causal evidence; a conversion that would have happened anyway isn't fully caused by marketing; automate repeatable decisions where models outperform manual judgment; systems must adapt to changing data; usable data is bounded by consent/governance; ultimately optimize business value, not vanity metrics.

## MARKETING MODELS
**What it covers:** repeatable decision logics for creating/delivering/capturing/measuring/optimizing demand — 15 families: Strategic (4Ps/7Ps/STP/positioning/GTM), Market & Competitive, Customer & Audience, Value & Positioning, Funnel & Journey, Channel & Distribution, Media, Targeting, Creative & Message, Format & Placement, Buying & Transaction, Delivery & Experience, Measurement & Attribution, Optimization & Learning, Economic & Growth.

**Key formula:** a marketing execution = M = O×A×T×C×P×F×U×Cr×B×D×Op (objective × audience × targeting × channel × placement × format × unit × creative × buying × delivery × optimization) — models are compositional, not a finite catalog.

**Vocabulary discipline table (use these definitions precisely):** Model = decision/behavioral/economic logic. Strategy = chosen direction. Channel = distribution environment. Placement = location within environment. Format = structural presentation type. Unit = atomic commercial object. Targeting = eligibility/selection logic. Creative = communication expression. Buying = transaction mechanism. Delivery = serving/exposure mechanism. Measurement = what's observed. Attribution = how credit is assigned. Optimization = how decisions change.

**Funnel/journey model options worth naming specifically:** AIDA, hierarchy-of-effects, awareness→consideration→conversion, TOFU/MOFU/BOFU, purchase funnel, flywheel (funnel is useful for diagnosis; flywheel — retention/advocacy feeding back into new prospects — is useful for growth architecture; both belong in the toolkit, neither replaces the other).

**Delivery-model taxonomy (how creative actually reaches the user, distinct from format):** static (one predetermined asset), dynamic (assembled from audience+context+product+offer+variant components), personalized (user data→prediction→message/creative/offer selection→delivery), sequential (ad1→interaction→ad2→interaction→ad3→conversion), retargeting delivery (visited→no conversion→audience pool→follow-up creative→conversion).

## MARKETING AUTOMATION
**What it covers:** the execution-and-decision orchestration layer. Core loop: **Signal → State → Decision → Action → Response → State update → next decision.** 11 domains, each with real substance worth knowing at the sub-domain level:

1. **Data Automation** — collection automation across page views, clicks, form submissions, email interactions, purchases, product usage, app events, webinar attendance, downloads, searches, cart activity, customer-service events, campaign/ad interactions, offline events; tasks: event capture, form capture, tracking, identity resolution, ingestion, CRM sync, enrichment, deduplication, normalization, field mapping, timestamping.
2. **Audience Automation** — continuously determines who belongs where, across demographic (age/gender/location/language), firmographic (industry/company size/revenue/geography/employee count), behavioral (pages visited/content consumed/products viewed/emails clicked/purchases/frequency), engagement (active/inactive/highly engaged/declining/re-engaged), transactional (first purchase/repeat/high-value/abandoned cart/subscription status), and intent (researching/evaluating/comparing/buying) segmentation — with the system automatically moving people between lifecycle states (Unknown→Visitor→Lead→MQL→SQL→Opportunity→Customer→Repeat Customer→Advocate).
3. **Lead Automation** — Capture → Enrichment → Identification → Segmentation → Scoring → Qualification → Nurturing → Routing → Assignment → Re-engagement → Sales Handoff. **Lead scoring mechanics concretely:** combine an **explicit score** (attribute fit — e.g. target industry +20, target company size +15, decision-maker title +25, target-market location +10) with a **behavioral score** (pricing-page visit +10, demo request +40, case-study download +15, email click +3, inactivity −10, unsubscribe −100); threshold triggers qualification and sales handoff (e.g. score ≥ 80). More advanced systems replace fixed point rules with predictive scoring.
4. **Journey Automation** — the point where automation becomes a state machine rather than a message sequence. Types: linear (A→B→C→D), branching (condition X→B, condition Y→C), event-driven (Event→Action→Wait→New Event→Action), lifecycle (Signup→Activation→Engagement→Purchase→Retention→Expansion), behavioral (Viewed product→Didn't purchase→Reminder→Viewed again→Offer), adaptive (next action depends on continuously updated behavior — the direction sophisticated systems are moving toward).
5. **Communication Automation** — outbound delivery by channel, each with its own format sub-taxonomy: Email (welcome, onboarding, nurture, newsletter, promotional, transactional-adjacent, abandoned cart, post-purchase, upsell, cross-sell, reactivation, win-back); SMS (reminders, promotions, abandoned cart, event notifications, transactional-adjacent messaging); Push (app engagement, reminders, promotions, behavioral triggers); In-app (onboarding, feature discovery, upgrade prompts, contextual offers); Web (popups, banners, recommendation modules, personalized content, dynamic CTAs); Messaging/chat (chatbot, conversational qualification, automated follow-up).
6. **Personalization Automation** — a distinct layer from communication: communication asks *should we contact this person?*, personalization asks *what should this person see?* Dimensions: identity, location, industry, lifecycle, behavior, intent, preferences, purchase history, engagement — flowing Customer state → Content decision → Message/offer/experience. Concrete outputs: personalized subject line, recommendation, offer, landing page, CTA, product ranking, content sequence, channel, and send time.
7. **Campaign Automation** — coordinating audience → creative → channel → schedule → workflow → messages → retargeting → follow-up → measurement; automatable tasks: campaign launch, audience enrollment, scheduling, channel activation, message sequencing, suppression, follow-ups, retargeting, campaign completion, reporting.
8. **Advertising Automation** — a distinct automation model because it automates *acquisition and removal* symmetrically. Audience sync: CRM audience → Audience sync → Ad platform → Activation. Retargeting: Viewed product → No purchase → Retargeting audience → Ad exposure. Suppression: Purchased → Remove from acquisition campaign (automation isn't only about adding people to campaigns — removing people from the *wrong* campaigns is equally important). Buying-side automation: bidding, budget allocation, audience selection, placement selection, frequency management, campaign pacing, creative rotation, conversion optimization.
9. **Lifecycle Automation** — the customer-state layer, tracking Prospect→Lead→Qualified Lead→Opportunity→Customer→Activated→Engaged→Repeat→High-Value→Advocate, and its reverse decay path Customer→Declining engagement→At-risk→Inactive→Churned — enabling onboarding, retention, expansion, cross-sell, upsell, renewal, reactivation, win-back, loyalty, and advocacy workflows.
10. **Optimization Automation** — moves automation from execution to decision-automation across audience/channel/timing/frequency/content/creative/offer/sequence/budget/placement/objective. Techniques: rule-based (IF engagement < threshold THEN reduce frequency), A/B and multivariate testing, send-time optimization (predicts individual best-engagement time), frequency optimization, channel optimization (Email vs SMS vs Push vs Web), next-best-action (Customer state → Candidate actions → Expected outcome → Best action), predictive optimization (conversion/churn/purchase/engagement/response probability, LTV), and reinforcement/adaptive optimization (continual learning from outcomes).
11. **Marketing Operations Automation** — the internal machinery: campaign setup, naming conventions, tagging, UTM generation, list management, data synchronization, lead routing, notifications, approvals, QA, reporting, workflow monitoring, error handling, compliance, permissions, suppression lists, campaign archival. This branch is boring until it breaks — then it becomes everyone's favorite topic.

**Automation Maturity Ladder (useful diagnostic for any automation request), with concrete examples per level:** Level 0 Manual → Level 1 Scheduled ("send newsletter every Monday") → Level 2 Rule-based ("if someone signs up, send welcome email") → Level 3 Behavior-triggered ("if they visit pricing, change the journey") → Level 4 Segment-aware ("high-value customers receive a different journey") → Level 5 Lifecycle-aware ("new customers get onboarding, not acquisition messaging") → Level 6 Multi-channel ("select between email, SMS, push and web") → Level 7 Predictive ("predict who is most likely to purchase") → Level 8 Decision-optimized ("select the action with highest expected business value") → Level 9 Adaptive ("change strategy based on observed results") → Level 10 Autonomous optimization ("continuously test, learn, allocate, suppress and optimize within defined constraints"). Ask "what level is this automation actually operating at?" before proposing an upgrade — most organizations self-report higher than Level 3–4 reality.

**Non-obvious principle:** suppression is automation too — preventing an inappropriate send matters as much as sending the right one. Every workflow needs an explicit exit condition or it becomes a zombie machine. A single trigger (e.g. cart abandonment) should route through the full decision stack, not jump straight to "send email": **Event** (cart abandoned) → **Identity** (who is this?) → **State** (existing customer? new prospect? VIP?) → **Eligibility** (can we contact them?) → **Segment** (high-value + recently active) → **Intent** (high purchase intent) → **Decision** (should we intervene?) → **Channel decision** (email/SMS/push) → **Timing decision** (immediately/2h/tomorrow) → **Content decision** (reminder/product benefits/incentive) → **Creative decision** (which message?) → **Offer decision** (discount/free shipping/none) → **Action** (send) → **Response** (open/click/purchase/ignore) → **Measurement** (revenue/conversion) → **Optimization** (change future decisions).

**10 classes of automation logic worth naming precisely:** Boolean (IF A AND B / OR / NOT), Conditional (IF customer THEN path A ELSE path B), Temporal (IF event happened AND N days passed AND no purchase THEN action), Threshold (IF score > 80 THEN qualify), Sequential (A→B→C→D), State-transition (Prospect→Lead→MQL→SQL→Customer), Ranking (rank candidate actions, choose highest-value), Predictive (probability of purchase = 0.73), Optimization (choose the action maximizing expected outcome), Feedback (Action→Outcome→Learning→New decision). Sophistication comes from moving static rules → dynamic decisioning → predictive/adaptive decisioning, not from adding more rules.

**9 automation axes to reason across independently** (not one taxonomy — a single automated campaign has values on all nine simultaneously): automation format (rule/workflow/journey/sequence/trigger/decision-engine/experiment), placement (inbox/website/app/SMS/push/ad-network/CRM), unit (person/lead/account/segment/message/creative/offer/budget), targeting mechanism, trigger (event/behavior/threshold/schedule/external event/score change), buying mechanism, creative mechanism (static/template/dynamic/AI-generated/adaptive), decision mechanism (rules/trees/scoring/prediction/ML/reinforcement), optimization objective (reach/engagement/conversions/revenue/ROAS/LTV/retention/margin).

**Result categories a mature automation system should be evaluated against** (not just "did it send"): Operational (tasks completed, campaigns launched, messages sent, audiences updated, records synced, leads routed), Audience (segments created, users qualified/suppressed/reclassified), Behavioral (opens, clicks, visits, engagement, content consumption), Funnel (leads, MQLs, SQLs, opportunities, conversions), Commercial (revenue, orders, AOV, CLV, retention, expansion), Optimization (winning creative/offer/channel/timing/frequency, improved conversion rate), Intelligence (predicted purchase probability, churn probability, intent, next-best-action, customer value, propensity). A system that only reports the first category (operational) is not yet demonstrating marketing value.

**How automation sits relative to the other marketing disciplines** (useful when a request seems to be "an automation problem" but is really upstream of it): Objectives → Strategy → Research → Psychology → Segmentation → Channels → Technology → **Automation** → Execution → Measurement → Optimization, looping back. Research tells automation what audiences need; psychology tells it why they behave that way; segmentation defines who they are; channels define where to reach them; technology supplies the infrastructure; automation executes the decision system; measurement reports what happened; optimization improves the decision system. Automation is the execution-and-decision orchestration layer connecting these — it consumes their outputs rather than replacing any of them. A request to "automate this campaign" that actually lacks a clear objective, segment definition, or channel fit is a strategy gap wearing an automation costume.

**Master formula, compressed:** Marketing Automation = Data + State + Signal + Audience + Logic + Decision + Journey + Channel + Content + Timing + Action + Measurement + Feedback + Optimization + Governance — or as a pipeline: Data → Identity → State → Signal → Eligibility → Audience → Intent/Score → Decision → Next Best Action → Channel → Placement → Creative → Offer → Timing → Delivery → Response → Measurement → Optimization → New State → Repeat. Formats, placements, units, targeting mechanisms, buying mechanisms, creative mechanisms, and optimization techniques are not seven competing categories to pick one from — they are seven simultaneous dimensions of any single automated action.

**10 core principles compressed:** automate decisions, not merely actions (sending is basic; deciding whether/when/where/why/what to send is intelligent automation); event before action (Signal→Decision→Action, never act blindly); state matters (same event, different action per customer state); context matters (a customer is not merely an email address); eligibility precedes personalization (don't personalize an action that should never happen); suppression is automation too; every action needs an objective (automation without one becomes automated noise); every automation needs an exit condition; every automated decision should be measurable; automation should reduce entropy over time, not accumulate complexity.

## MARKETING OPERATIONS
**What it covers:** the coordination/control layer across all other marketing disciplines (not another list of activities alongside strategy/tactics/channels — it's what organizes, executes, measures, governs and optimizes all of them). A simplified operating-system dependency chain runs Objectives → Planning → Budget → Audience → Channel/Media → Creative/Content → Campaign → Execution → Data Collection → Measurement → Optimization → Learning → next decision, underpinned throughout by People, Systems, Data, Processes, Governance, Technology, Vendors, and Money. 20 domains, several worth knowing at concrete resolution:

**1. Operating Model** — the organizational architecture: centralized, decentralized, federated/hybrid, global, regional, business-unit, product-led, brand-led, revenue-aligned, customer-lifecycle, campaign-centric, or channel-centric operations. Core logic: WHO does WHAT, WHEN, using WHICH SYSTEM, under WHICH AUTHORITY, producing WHICH OUTPUT. Tasks: organizational design, role definition, RACI management, approval structures, workflow design, escalation paths, operating cadence, planning cycles, reporting hierarchy, cross-functional coordination, SLAs, process documentation.

**2. Planning & Orchestration** — converts objectives into executable work through a planning-unit cascade: Strategic Plan → Annual Plan → Quarterly Plan → Monthly Plan → Campaign Plan → Channel Plan → Execution Task. Planning is fundamentally a constraint-solving problem: Objective + Deadline + Budget + Resources + Audience + Channels + Dependencies = Executable Plan. Concrete outputs: marketing calendar, campaign roadmap, launch schedule, resource plan, campaign brief, execution backlog, dependency map.

**3. Budget & Financial Ops** — budget structures worth naming: corporate, business-unit, product, geography, campaign, channel, media, creative, technology, agency, event, and experimental budgets. **Budgeting mechanisms:** fixed, flexible, incremental, zero-based, percentage-of-revenue, objective-and-task, performance-based allocation, portfolio allocation, contingency allocation — each implies a different capital feedback loop (Available Capital → Expected Return → Risk → Strategic Importance → Resource Constraint → Allocation → Observed Return → Reallocation). Tasks: creation, allocation, reallocation, spend tracking, invoice management, purchase orders, vendor payments, accruals, forecasting, budget-variance analysis, ROI/CAC/ROAS analysis, marginal-return analysis.

**4. Campaign Operations hierarchy:** Marketing Objective → Campaign → Campaign Flight → Channel → Placement → Audience → Creative → Ad/Message → Impression/Interaction → Conversion. **Campaign format taxonomy:** brand, acquisition, demand-generation, product, promotional, seasonal, launch, retention, win-back, event, account-based, cross-sell, upsell, awareness, and direct-response campaigns. Campaign mechanics worth naming precisely: creation, configuration, naming/tagging conventions, scheduling, activation/pausing, duplication/versioning, QA, trafficking, monitoring, reporting, closure, post-campaign analysis (the operational "boring until it breaks" layer most taxonomies skip).

**5–6. Channel & Media Ops** — channels decompose into Format, Placement, Inventory, Audience, Buying Mechanism, Creative Mechanism, Delivery Mechanism, Measurement, Optimization. Channel families by ownership: Owned (website, app, email, SMS, CRM, customer portal, blog, community); Paid (search, social, display, video, audio, retail media, native, sponsorships, influencer paid media, affiliate); Earned (PR, organic social, reviews, word of mouth, editorial coverage, organic search); Physical (retail, outdoor, print, direct mail, events, experiential, point-of-sale). Media operations formalizes format ≠ placement ≠ audience ≠ buying ≠ creative as distinct dimensions of one execution unit — e.g. Video (format) ≠ YouTube pre-roll (placement) ≠ 18–34-year-old sports enthusiasts (audience) ≠ CPM (buying) ≠ 6-second video (creative spec). Buying mechanisms by acquisition path: Direct (publisher purchase, sponsorship, reservation, negotiated placement); Programmatic (open auction, private marketplace, programmatic guaranteed, preferred deal); Search (keyword auction, shopping auction); Social (auction, platform-managed delivery); Partnership (affiliate, influencer, sponsorship, revenue share). Pricing models: CPM, CPC, CPA, CPL, CPV, CPI, CPE, CPS, fixed fee, percentage revenue, performance commission.

**7. Audience & Targeting Ops** — targeting taxonomy: demographic, geographic, firmographic, psychographic, behavioral, contextual, intent, transactional, lifecycle, relationship, account-based, device, time-based, frequency-based, predictive, lookalike, retargeting, first-party audience — each with named mechanisms (e.g. demographic = age/gender/household/income/education; geographic = country/state/city/postal code/radius/geo-fence; contextual = targeting the environment rather than the person, e.g. an article about running triggering a running-shoe ad).

Creative formats: headline, body copy, static image, GIF, animation, video (short/long), audio, infographic, interactive creative, product feed, catalog, email template, landing page. Operational tasks: briefing, ideation, production, adaptation, localization, versioning, resizing, approval, rights management, asset tagging/storage, distribution, retirement. **9. MarTech Ops** — major systems requiring active operational management (not just procurement): CRM, CDP, marketing automation, CMS, DAM, analytics, attribution, ad platforms, DSP, SSP, DMP, experimentation platforms, personalization systems, consent-management platforms, workflow systems, reporting systems. Tasks: implementation, configuration, integration, permissions, data synchronization, system maintenance, platform governance, API management, data mapping, identity resolution, troubleshooting, system QA, technology evaluation, vendor management.

**15. **16. Experimentation & Optimization Ops** — Business Question → Hypothesis → Variable → Experiment → Treatment/Control → Measurement → Statistical Evaluation → Decision → Rollout/Rejection, applied across A/B, multivariate, holdout, incrementality, geo, audience, creative, offer, landing-page, bid, budget, frequency, placement, channel, and portfolio optimization.

**17. Compliance, Governance & Risk** — domains: privacy, consent, data access, data retention, brand governance, creative approval, regulatory compliance, advertising policies, platform policies, security, permissions, auditability, vendor compliance. Core logic: Action Requested → Permission? → Policy? → Consent? → Risk? → Approval? → Execute.

**18. Performance Management** — operational KPIs by category: Speed (campaign launch time, approval time, production cycle time, time-to-market), Quality (error rate, rejected assets, tracking failures, data-quality failures), Efficiency (cost per campaign/asset, automation rate, labor utilization), Reliability (platform uptime, integration success, data freshness, workflow completion), Marketing performance (CAC, ROI, ROAS, pipeline, revenue, retention).

**19–20. Intelligence & Decision Ops, Continuous Improvement** — gathers Data + Performance + Audience Signals + Market Signals + Financial Signals + Operational Signals and converts them through Observation → Diagnosis → Prediction → Recommendation → Decision → Action. Five output classes a mature operations function should produce: Execution outputs (campaigns, ads, emails, content, events, promotions, workflows, communications), Data outputs (impressions, clicks, leads, conversions, revenue, customer events, audience signals), Decision outputs (budget/targeting/channel/creative/optimization/resource decisions), Management outputs (dashboards, reports, forecasts, plans, calendars, budgets, performance reviews), Learning outputs (winning audiences/creatives/channels, failed hypotheses, marginal-return curves, customer insights, operational improvements) — the fifth category is what separates a mature operations function from a pure execution shop: every execution should generate knowledge that improves the next one.

**The relationship graph tying campaign operations together** (worth holding as one picture): Marketing Objective → Campaign → three parallel branches (Audience, Channel→Platform→Placement, Budget) converging on Format → Creative → Buying Method → Bid → Delivery → Exposure → Interaction → Conversion → Revenue → Measurement → Attribution → Optimization, which splits back into Creative Change and Audience Change feeding the Next Cycle. This is the closed-loop operating system underneath any specific campaign-ops question — most "why isn't this campaign working" diagnoses are really asking which node in this loop is broken (wrong audience feeding format, format mismatched to placement, buying method starving delivery, or the optimization step never actually closing the loop back to creative/audience).

**A fully specified marketing execution unit is a 12-part tuple**, not "an ad": Objective × Audience × Channel × Placement × Format × Creative × Buying Method × Budget × Timing × Delivery Rule × Measurement × Optimization. Example instantiation: Objective=acquisition, Audience=high-intent prospects, Channel=paid search, Placement=search results, Format=text ad, Creative=keyword-specific message, Buying=CPC auction, Budget=₹X/day, Timing=business hours, Delivery=automated bidding, Measurement=qualified conversion, Optimization=conversion-value maximization. Treat any operations brief that only specifies 2–3 of these twelve as incomplete, not as a finished spec.

**12 logic types worth reusing generically:** Rule logic (IF/THEN), Eligibility logic (qualify/exclude), Routing logic (classify→destination), Scoring logic (signals→weights→score→threshold→action), Allocation logic (resources→expected return→constraints→allocation), Auction logic, Scheduling logic, Optimization logic (state→signal→deviation→adjustment), Attribution logic, Forecasting logic, Experimentation logic, Governance logic (request→permission→policy→risk→approval→execute).

**20 principles compress to:** consistency, modularity, automate the deterministic/preserve human judgment for the ambiguous, traceability, measurability, standardization with flexibility for exceptions, data integrity, governance at scale, closed feedback loops, incrementality discipline, resource efficiency, customer relevance over pure efficiency, scalability (10x volume without 10x labor), interoperability, observability, experimentation over guessing, continuous optimization of the process itself.

## MARKETING OPTIMIZATION
**What it covers:** systematic selection/allocation/adaptation under objectives, constraints, uncertainty and feedback — 18 domains covering Objective, Audience, Channel, Inventory/Placement, Format, Unit, Targeting, Buying, Creative, Offer/Conversion, Timing, Frequency, Journey, Budget, Conversion, Portfolio, Experimentation, and Automated/Algorithmic optimization.

**The seven variables every optimizer controls:** Who (audience), Where (channel/placement), What (creative/offer), When (timing), How often (frequency), How much (bid/budget), In what sequence (journey). Optimization vector: **O = (A, C, P, F, T, R, B, S)**.

**Formalism worth keeping:** a* = argmax_a E[U(a|x)] — given context x, pick the action maximizing expected utility, not the action with the best average historical metric. Marginal-value thinking beats average-value thinking everywhere: rank audiences/channels by *expected economic value at the margin* (next ₹1, next segment), not by size or current ROAS.

**Type ladder for optimization technique itself:** Rule-based → Statistical → Predictive → Dynamic (continuously updating) → Reinforcement/sequential (optimizes long-term value, not immediate response) — roughly mirrors the automation maturity ladder above.

**10 principles:** optimize the objective, not the metric (CTR isn't the goal unless it creates value); optimize marginal value; every optimization has constraints (max f(x) subject to g_i(x) ≤ C_i); predictions are uncertain — respect confidence intervals; **correlation isn't incrementality** (an audience can show great ROAS because it was buying anyway); avoid local optimization (optimizing each component independently can still produce a worse system — optimize the system, not the piece); adapt continuously as conditions shift; balance exploration (discover what might work) with exploitation (spend more on what works); optimization requires feedback or there's no learning.

**Keep four things distinct:** Optimization *dimensions* (what's optimized: audience, channel, creative...) vs. *techniques* (how: A/B test, regression, bandits, reinforcement learning...) vs. *objectives* (why: reach, conversions, profit, LTV...) vs. *constraints* (limits: budget, brand rules, privacy).

**Concrete example of the utility-vs-size trap (a pattern worth applying whenever asked to prioritize audiences/channels):** Audience A: 100,000 users, 1.2% CVR, ₹2,000 AOV. Audience B: 20,000 users, 5.5% CVR, ₹3,000 AOV. Audience C: 5,000 users, 11% CVR, ₹4,500 AOV. A naive read favors A's size; an optimizer favors whichever has the highest *expected economic value*, which can easily be C. The same logic applies to budget allocation: don't move all spend to the channel with the best marginal ROAS today — returns decay, so balance marginal returns across channels subject to constraints rather than fully concentrating.

**Optimization-node schema** (the resolution to describe any specific optimization problem at, useful when a task asks "how would you optimize X"): Definition, Purpose, Parent/child category, Decision variable, Input data/signals, Eligibility conditions, Constraints, Objective function, Optimization technique, Decision logic, Prediction model, Control mechanism, Execution mechanism, Feedback mechanism, Measurement requirements, Experimentation method, Output, KPI, Failure modes, Trade-offs, Dependencies.

## MARKETING MEASUREMENT
**What it covers:** the sensing/evidence layer operating at every level of the system, not just campaign-end reporting. Progression of result classes: **Descriptive → Diagnostic → Comparative → Attribution → Causal → Predictive → Prescriptive → Economic.**

**Attribution vs. Incrementality (critical, frequently conflated):** Attribution asks "who gets credit?" (first-touch, last-touch, linear, time-decay, position-based, algorithmic/Shapley-value/Markov-chain). Incrementality asks "did marketing actually cause additional outcomes?" via **Incremental Lift = Outcome(Treatment) − Outcome(Control)**, using randomized experiments (A/B, holdouts, geo experiments) or quasi-experimental methods (diff-in-diff, regression discontinuity, synthetic control, matched-market). Two campaigns can report identical attributed conversions with wildly different real incremental value.

**Financial core formulas:** CAC = (Marketing + Acquisition Cost) / New Customers. ROAS = Revenue / Ad Spend. ROI = (Return − Cost) / Cost. LTV:CAC = Customer Lifetime Value / CAC.

**Cohort measurement** (group by shared starting condition — acquisition month/channel/campaign — then track retention/revenue/LTV over time) reveals whether performance is improving over time in ways aggregate reporting hides.

**Six-dimensional measurement model** (mirrors the Formats/Intelligence frame): Format, Placement, Unit, Targeting, Buying, Creative, with Optimization sitting above as the action layer.

**20 principles compress to:** start from a decision, not a dashboard; define the unit before the metric; separate observation from inference; correlation ≠ causation; attribution ≠ incrementality; optimize economic outcomes not vanity metrics; measure quality not just volume; consistent definitions; account for time lag, selection bias, seasonality, overlapping audiences; distinguish new vs. returning customers; measure marginal not just average returns; use experiments where causal certainty matters; don't confuse platform-reported numbers with business truth; **measurement should always produce an action** — "CTR fell 18%" is measurement; "CTR fell 18% because of audience saturation; move 15% of spend to the underexposed segment" is intelligence built on measurement.

**Metric-family taxonomy** (classify any requested metric into one of these before reporting it, to avoid mixing incompatible metric types in one comparison): Volume (impressions, clicks, leads, conversions — raw counts), Rate (CTR, CVR, open rate — ratios of an event to an opportunity), Cost (CPM/CPC/CPA/CPL/CAC), Value (revenue, AOV, LTV, contribution margin), Ratio (ROAS, ROI, LTV:CAC), Time (time-to-conversion, session duration, payback period), Distribution (percentile/variance measures — useful when averages hide the real story, e.g. a "good average CPA" masking a bimodal audience).

**Brand measurement is structurally different from performance measurement** — it needs its own stack: awareness (unaided/aided/recall/recognition), perception (associations/preference/consideration/relevance/differentiation), behavior (search lift, direct traffic, branded search, share of voice/search), equity (a composite of the above). Never force brand objectives through a direct-response measurement lens (e.g. judging a salience campaign purely on last-click sales).

## MARKETING RESEARCH
**What it covers:** evidence generation, organized by **purpose** (Exploratory→Descriptive→Diagnostic→Causal→Predictive→Prescriptive — a ladder: Describe→Compare→Explain→Causally test→Predict→Optimize), **domain** (market/customer/consumer/competitor/product/brand/pricing/advertising/media research), **method** (secondary vs. primary; qualitative "what does it mean" vs. quantitative "how much/how many" — strongest systems combine both), and **acquisition mechanism** (surveys, interviews, focus groups, observation, ethnography, experiments, panels, social listening).

**Non-obvious distinctions:** Customer ≠ Consumer ≠ Prospect. Stated behavior ≠ observed behavior (why observational/ethnographic research exists — people are poor reporters of their own behavior). Sample ≠ population. Statistical significance ≠ business significance.

**Output ladder (do not conflate these):** Data ("what respondents said") → Finding ("62% selected option A") → Insight ("price uncertainty is a major barrier among first-time buyers") → Recommendation ("introduce transparent entry-level pricing") → Decision ("launch it") → Action → Outcome.

**Pricing-research methods worth naming specifically:** Van Westendorp, Gabor-Granger, conjoint analysis, choice modeling.

**Master formula:** Research = Question × Population × Object × Context × Method × Evidence × Analysis × Decision. Same research objective (e.g. "research willingness to pay") can be answered via completely different valid architectures (survey+Van Westendorp+quant vs. experimental+conjoint+quant vs. transaction-data+A/B) — there is no single correct method per question.

**Research-domain taxonomy** (name the right domain before choosing a method): Market, Customer, Consumer (broader than Customer — includes people who know/consider/reject the brand or buy competitors), Competitive, Product (need discovery → concept → feature → prototype → usability → PMF → naming/packaging/positioning → post-launch), Brand, Pricing, Advertising (exposure→attention→comprehension→memory→attitude→intent→behavior→business outcome), Media, Digital (user→session→page→event→interaction→conversion→transaction granularity).

**Analytical-logic ladder** (mirrors the intelligence maturity ladder, applied specifically to research analysis): Descriptive ("what happened") → Comparative ("how does A differ from B") → Correlational ("what moves together") → Diagnostic ("what explains it") → Causal ("did X cause Y") → Predictive ("what's next") → Prescriptive ("what action produces the best expected result").

**7 principles:** question before method; evidence before interpretation (observed vs. inferred vs. recommended must stay separated); correlation ≠ causation; stated behavior ≠ observed behavior; sample ≠ population; statistical significance ≠ business significance; research reduces uncertainty, it never eliminates it.

## MARKETING STRATEGIES
**What it covers:** the competitive/directional layer — 8 domains: Market, Brand, Growth, Customer, Competitive, Communication, Digital, Advanced (portfolio/ecosystem/platform/network-effects/behavioral/predictive/AI strategy). Strategy answers: where to compete → whom to serve → what value to create → how to communicate it → how to acquire/grow customers → how to defend the position → how to allocate resources → how to optimize the system.

**Competitive-position playbooks (classic, still load-bearing):**
- **Market leader** — defend share, expand the category, increase usage/frequency, raise switching costs.
- **Challenger** — direct/indirect/flank/niche attack; price/product/service/technology/positioning disruption.
- **Follower** — imitation, adaptation, selective differentiation, cost efficiency.
- **Nicher** — geographic/demographic/behavioral/premium/technical niche, specialist positioning.

Competitors can be countered by: ignore, monitor, match, counter, reposition, differentiate, accelerate, preempt, acquire, partner, or attack a different segment.

**Positioning axes companies compete on:** price, quality, performance, features, innovation, convenience, speed, service, trust, experience, status, community, specialization, distribution, technology, brand. The goal isn't "be different" — it's **be different on something customers value that competitors can't easily neutralize.**

**14 principles compress to:** perceived value must exceed price+effort+risk+friction; segmentation (no one strategy fits everyone); positioning (need a meaningful mental position vs. alternatives); differentiation only matters if customers care; relevance (right message, wrong person, still bad marketing); timing changes outcomes; reduce friction; consistency strengthens memory; distinctiveness is strategically valuable; claims need proof; growth needs viable unit economics; correlation ≠ causation (incrementality again); the strongest systems build compounding assets (brand, content, SEO, first-party data, community, network effects); every action should feed learning back in.

**8 reducing strategic questions:** Where? (market) / Who? (customer) / Why us? (brand+competitive) / What value? (offer) / What do we say? (communication) / How do we reach them? (digital+media) / How do we grow? (growth) / How do we adapt? (advanced strategy).

**Growth-strategy sub-map** (Domain III): Acquisition, Activation, Conversion, Retention, Revenue Expansion (cross-sell/upsell), Referral, Growth Loops (a self-reinforcing cycle — output of one cycle becomes input to the next — distinct from a one-directional funnel), Product-Led vs. Market-Led growth. Growth strategies interact with Customer Strategies (segmentation, experience, lifecycle, loyalty, personalization, customer value) — treat growth and customer strategy as two views of the same underlying system, not separate domains.

**Strategy carries 18 decomposable dimensions** worth checking any strategy brief against: Objective, Market, Audience, Need, Value, Position, Offer, Message, Format, Placement, Targeting, Buying, Creative, Journey, Channel, Economics, Optimization, Measurement. A brief that only specifies 2–3 of these (e.g. "target Gen Z on TikTok") is not yet a strategy — it's a targeting/channel decision inside an unstated strategy.

## MARKETING LOGICS
**What it covers — an actual distinct logic-type taxonomy, not executable branching rules.** Six core operational logics plus three cross-cutting layers:

**Level 1 — Core operational logics:**
| Logic | Answers | Key sub-types |
|---|---|---|
| **Targeting** | Who should receive this? | demographic, geographic, behavioral, contextual, intent, predictive, lookalike, lifecycle, account, exclusion (negative), sequential, frequency-based |
| **Decision** | What should the system do? | rule-based (IF/THEN), score-based (weighted sum vs. threshold), **probability-based** (P(Y=1\|X)), **utility-based** (probability × expected value — a 50%-probability/₹2,000-value customer can beat an 80%-probability/₹100-value one), constraint-based, multi-objective (weighted composite of revenue/profit/retention/brand), sequential (state→action→outcome→next state), attribution, incrementality, exploration-vs-exploitation |
| **Personalization** | What should this person see? | 8 levels: attribute (name) → segment → behavioral → intent-based → predictive → real-time (changes mid-session) → journey-spanning → generative (system creates the variant) |
| **Conversion** | What causes the desired action? | intent, motivation, friction, trust, offer, CTA, funnel, abandonment, retention |
| **Pricing** | What price logic applies? | cost-plus, competitor-based, value-based, willingness-to-pay, elasticity, dynamic pricing, promotion/discount, pack architecture, revenue management |
| **Budget** | Where should money go? | allocation, objective-based allocation, marginal return, CAC, LTV:CAC, ROAS, profit, incremental, pacing, risk-adjusted |

**Level 0 — Input logics** (precede the six): Signal logic (what happened), Data logic (what's available), Identity logic (whose signal), Feature logic (raw signal → usable variable, e.g. "visited product page 10:43pm" → `product_page_visits_7d=4, recency=2h, intent_score=87`).

**Level 2 — Optimization logics** (operate across the six): allocation, ranking, selection, sequencing, timing, frequency, attribution, incrementality, experimentation, learning.

**Level 3 — Control logics** (govern autonomy): constraint, eligibility, safety, compliance, guardrail, escalation (when should a human intervene), exception handling.

**Why this matters as a distinct reference:** the six core logics form a dependency graph, not independent modules — Targeting → Decision → Personalization → Conversion → (Pricing → Revenue) → Budget → Optimization → back to Targeting. Use this table to name *which type of reasoning* a marketing problem actually requires (e.g. "should we discount this segment" is Pricing+Utility-based Decision logic; "which email variant for this user" is Personalization Level 5-6).

### RFM Segmentation Methodology

**Recency, Frequency, Monetary** — a transactional-segmentation methodology `rfm-segmentation-subagent` runs, distinct from the Audience Automation segmentation dimensions above (which classify by attribute; RFM classifies by transaction behavior specifically).

**Scoring mechanics:** score each of the three dimensions independently, commonly quintile-based (1-5, where 5 is best: most recent, most frequent, highest monetary value) — a rule-based fixed-threshold approach also works for smaller datasets where quintiles would be too coarse. Combine the three scores (often written as a three-digit code, e.g. "545" = highest recency, highest frequency, mid monetary) into a named segment.

**Canonical segment definitions** (thresholds are illustrative — always state the actual thresholds applied, since "canonical" doesn't mean universal):
| Segment | R | F | M | Typical action |
|---|---|---|---|---|
| Champions | High | High | High | Reward, ask for referrals/reviews |
| Loyal Customers | Mid-High | High | Mid-High | Upsell higher-value products |
| At-Risk | Low (declining) | High | High | Win-back campaign, urgency |
| Hibernating | Low | Low | Low | Low-cost reactivation or let go |
| New Customers | High | Low | Varies | Onboarding, not yet scoreable on F/M |

**Reproducibility requirement:** an RFM segmentation is only a real deliverable if the threshold methodology is stated explicitly (quintile-based, fixed-value, or otherwise) — an unreproducible segmentation is a judgment call with numbers attached, not an analysis. RFM requires genuine transactional data (order/purchase records); it cannot be run on engagement proxies (email opens, site visits) — that's a different, adjacent methodology (behavioral/engagement segmentation, covered under Audience Automation above).

### Naming & Verbal Identity Frameworks

The structural process `naming-verbal-identity-subagent` runs when briefing a new name or tagline:

**Naming approach taxonomy:** descriptive (states what it does — "General Motors" — lowest differentiation, highest immediate clarity), suggestive (implies a benefit or attribute without stating it literally — "Dropbox"), arbitrary/real-word (an existing word applied out of context — "Apple," "Amazon"), coined/invented (a constructed word — "Kodak," "Xerox" — highest differentiation and trademark-defensibility, highest initial-awareness cost since it carries no built-in meaning), and compound/portmanteau (blending two real words — "Pinterest," "Instagram").

**Evaluation criteria, checked in order:** (1) Availability — can it actually be used (domain, social handles, and a basic trademark-conflict spot-check, never a substitute for real legal clearance); (2) Pronounceability/memorability — can it be said and recalled correctly on first hearing, across the brand's actual target markets and languages; (3) Meaning/connotation check across relevant languages/markets — a name that means something unfortunate in a key target language is a real, recurring failure mode; (4) Differentiation — does it stand apart from named competitors, not just sound "nice"; (5) Extensibility — does it still work if the company's offering expands beyond its current scope (a name too literally tied to one product category constrains future positioning).

**Tagline construction patterns:** benefit-led ("Just Do It" implies empowerment/action), descriptive ("The Ultimate Driving Machine"), imperative/call-to-action, and emotional/aspirational — matched to whichever the core positioning claim (see Brand & Creative Marketing KB §1.1-1.3) actually needs reinforced, never chosen for wordplay appeal alone if it doesn't carry the positioning.

**Refusal-relevant fact:** an available domain/handle check and a "no obvious conflict found" web search are NOT a trademark clearance — never state a name is legally "clear" without real counsel and a professional search; this sub-agent can flag an obvious conflict, never certify the absence of one.

### Social Commerce & Shoppable Content

The mechanics `social-commerce-shoppable-content-subagent` specifies, distinct from general Social Media Advertising (which is about paid distribution) — social commerce is about completing a transaction without leaving the social surface:

**Mechanism taxonomy:** in-feed product tagging (a post/Reel tags specific products, tapping through to a product detail view within the app), native checkout (transaction completes without leaving the platform — the highest-conversion, lowest-friction mechanism where available, but cedes first-party customer data to the platform), platform-to-site handoff (tap-through to the brand's own site to complete checkout — lower conversion, but the brand retains the full customer relationship and data), and live-shopping/livestream commerce (a live video with real-time product tagging and often time-boxed offers — highest engagement, requires the same real-time-logistics discipline as general live-streaming, see Brand & Creative Marketing KB §2.3c).

**The data-ownership tradeoff, stated plainly:** native in-platform checkout typically converts better but hands the platform the customer relationship (the platform, not the brand, holds the email/payment/repeat-purchase relationship) — a brand with a genuine CRM/retention strategy (see Revenue/CRM Agent's lifecycle work) should weigh this tradeoff explicitly rather than defaulting to whichever mechanism converts best in isolation.

**Content-format fit:** product-tagged static posts and carousels for considered-purchase categories (the buyer wants to see detail before committing), short-form video (Reels/TikTok-native) for impulse/discovery-driven categories, and live-shopping for high-consideration or scarcity-driven drops (limited inventory, exclusive releases) where real-time urgency itself is part of the conversion mechanism.

# WHAT THIS KNOWLEDGE BASE DOES NOT COVER

This file is **theoretical/taxonomic knowledge** — concepts, hierarchies, distinctions, and vocabulary for reasoning about marketing problems. It is explicitly not:

- **A procedure to execute.** There is no branching logic, decision tree, or workflow here that the agent should "run." When a task requires actually *doing* something — extracting a brand's voice from existing content, building a psychographic customer profile, running a specific campaign-build process, generating creative variants, executing a measurement pipeline — call the corresponding **Skill** from the procedural Skills library (e.g. `brand-voice-extractor`, `psychographic-profiler`, and similar execution-oriented skills). This KB tells the agent *what a brand-voice concept is and how it fits the broader system*; the Skill tells it *how to extract one from real inputs*.
- **A source of current facts, numbers, or platform specifics.** Nothing here should be treated as up-to-date pricing, current ad-platform features, current algorithm behavior, or live competitive data — the corpus is conceptual, not a live feed. Verify anything time-sensitive independently — but know the real limit of the verification tool before trusting a negative result from it: `WebFetch` returns a page's rendered text, not its raw markup, so a JS-rendered directory/listing page, a schema/JSON-LD block, or any client-side-built content routinely comes back as an empty shell even when the page genuinely has what you're checking for. That's a failed lookup, not confirmation of absence. Before reporting such a check as unverifiable, run `python ~/Tantra/.claude/lib/browser_render.py <url> --out <path>` — a self-hosted, free real-browser fallback any agent with Bash access can call directly (it stops and reports `status: "blocked"` on a genuine bot-challenge rather than trying to get past one). It was built for the Website Development Agent but is explicitly meant for "any agent that hits the same ceiling," per its own file header — this is that pointer, for the agents across every system who hit it independently before learning it existed. **One real exception this fallback does not cover:** X/Twitter's read API now returns HTTP 402 (Payment Required) on basic profile/follower checks — a genuine paywall, not a rendering limitation, and not something a real-browser fallback resolves either, since the platform restricts automated and logged-out browsing well beyond what a plain page load gets past, and this framework refuses any stealth/evasion technique that would be needed to get around a real access wall. Report current X/Twitter follower or engagement figures as not obtainable with this system's free tooling, full stop — not as a lookup to keep retrying or working around.
- **A substitute for actual customer/market data.** The frameworks above (segmentation dimensions, journey stages, intelligence types) are structures to apply *to* real data, not a replacement for it.
- **Legal, regulatory, or compliance advice.** Regulatory Knowledge is referenced here only as a category placeholder ("what can/can't be done") — it is not a compliance checklist and must not be treated as one.
