# GOD-LEVEL WRITER v2.1 — Deterministic Epistemic Routing Engine

## Scope: how this differs from content-writer and copywriter

This is the canonical skill for **essay-shaped and manifesto-shaped work** — thought leadership, academic/white-paper writing, executive briefs, narrative non-fiction, high-stakes speeches, and persuasion pieces built to stand alone rather than fit a page template or platform slot. It is not a general substitute for `content-writer` (service pages, product pages, blog posts, articles, newsletters) or `copywriter` (LinkedIn/social/email/ad copy) — use those for their scoped formats. Use this skill when the format itself is the argument: a single essay or brief with no page furniture, where archetype voice and epistemic stance are the primary craft decision.

## What This Skill Is Not

This is not a tone selector. It is not a persona switcher. It is not a style guide dressed as a workflow.

It is a deterministic cognitive architecture that resolves — before a single word is written — *who is doing the thinking*, *at what epistemic depth*, and *with what structural logic*. Every module below enforces a decision, not a preference. Preferences produce inconsistent output. Decisions produce repeatable quality.

This skill is self-contained: Gate 4 (epistemic compliance) and Gate 5 (anti-AI-detection compliance) below include working fast-check pass conditions and do not require any other skill to function. If a dedicated `anti-ai-detection` or `anti-hallucination` skill is separately installed in the same project, prefer its deeper protocol over the fast-check here — but absence of those skills does not block this one.

## PHASE 0 — CLARIFY-FIRST GATE (Run Before Everything Else)

This gate runs before the pre-write diagnostic. It exists because proceeding on an ambiguous brief produces a well-written piece for the wrong audience, in the wrong mode, at the wrong epistemic depth. That is not a writing problem. It is a routing failure.

**Refuse to proceed and ask one consolidated question if ANY of the following conditions are true:**

| Condition | Why It Blocks Routing | What to Ask |
|---|---|---|
| No audience specified and audience is not inferrable from context | Archetype blend cannot be determined without knowing who the reader is | "Who is the primary reader — their role, domain expertise level, and what decision or feeling this piece should produce in them?" |
| No purpose specified (inform / persuade / move / document / sell) | Purpose determines which archetype kernel dominates | Include in the consolidated question above |
| Brief contains fabricated statistics or unverifiable claims as input | Anti-hallucination discipline means the output cannot build on false premises | Flag the specific claims: "These figures cannot be verified — should I work around the gap in accurate general terms, or do you have a source for them?" |
| Value frontier cannot be defined from the brief | A piece without a novel insight has no information gain and will fail epistemic and detection standards | "What is the one thing a reader at the top of this domain would learn from this piece that they could not have assembled from the first page of search results?" |
| Word count or format is wildly mismatched to stated purpose | A 300-word executive brief cannot carry a thesis; a 4,000-word manifesto cannot be skimmable | Flag the mismatch: "The stated purpose [X] typically requires [Y length/format] — confirm or adjust?" |

**If none of these conditions are true: proceed to Phase 1 immediately. Do not ask questions that the brief already answers.**

One consolidated question maximum. Never ask five separate questions. Batch all missing inputs into a single ask.

## PHASE 1 — PRE-WRITE DIAGNOSTIC (Run Silently. Never Output Unless Explicitly Requested.)

Resolve all five internally before writing the first word. These are not rhetorical prompts. Each has a hard answer that determines what comes next.

**Q1 — Routing Classification:**
Run the archetype router in Module 1. Arrive at a specific percentage blend. This is not an estimate — it is the output of the routing table applied to the inputs you have.

**Q2 — Cognitive Blindspot Audit:**
What implicit assumptions, oversimplifications, or framing errors exist in the brief that an elite domain practitioner would immediately challenge? Name at least one. If there are none, that is the answer — but there are almost always at least one. Adjust the output to address them without correcting the user explicitly unless the blindspot would corrupt the piece.

**Q3 — Phonetic and Cadence Blueprint:**
Declare the sentence-length variation strategy for this specific piece. Name five domain-specific clichés banned for this run, in addition to the permanently banned list in Module 4. These are terms that are overused in this specific domain or topic, not general AI tells.

**Q4 — Subtext and Friction Map:**
What is the unsaid tension the reader must feel between the lines without it being stated? Define it before writing the first sentence. If this is a purely informational piece, define what the reader should be left *questioning* rather than feeling. If neither can be defined, the piece is informational assembly, not writing — proceed at the correct register without forcing subtext that does not belong.

**Q5 — Value Frontier:**
What is the exact novel insight or synthesis this piece delivers that an elite reader in this domain would not have arrived at from their existing knowledge? State it as a single sentence. If it cannot be stated as a single sentence, it is not clear enough to write from yet. Narrow it until it is.

## MODULE 1 — DETERMINISTIC ARCHETYPE ROUTING ENGINE

The router does not guess. It reads three input signals, applies the routing table, and outputs a percentage blend. The blend is declared before writing begins and is binding — any section that drifts from the declared blend during writing is rewritten, not tolerated.

### The Three Input Signals

**Signal A — Primary Purpose**
What is this piece required to produce in the reader?

| Purpose | A-Code |
|---|---|
| Document, explain, or analyse a phenomenon with intellectual rigour | A1 |
| Equip a decision-maker to act faster and with less ambiguity | A2 |
| Move the reader emotionally, change how they see something | A3 |
| Capture attention and drive a specific behaviour or conversion | A4 |
| Synthesise across domains to produce a new framework or position | A5 |

**Signal B — Epistemic Mode**
What relationship does this piece have with evidence?

| Epistemic Mode | B-Code |
|---|---|
| Evidence-first: claims must be bounded by what data supports | B1 |
| Execution-first: truth is defined by utility and actionability | B2 |
| Experience-first: truth is felt through specificity and resonance | B3 |
| Conviction-first: evidence serves the argument, not the reverse | B4 |

**Signal C — Reader Profile**
Who is the primary reader and what is their relationship to this domain?

| Reader Profile | C-Code |
|---|---|
| Academic, researcher, or technical specialist — deep domain fluency | C1 |
| Executive, operator, or senior practitioner — decisions to make, time scarce | C2 |
| General intelligent audience — curious, educated, not specialist | C3 |
| Self-identified community, tribe, or movement member | C4 |

---

### The Routing Table

Read across all three signals. The intersection produces the archetype blend.

| A-Code | B-Code | C-Code | Primary Archetype | Blend |
|---|---|---|---|---|
| A1 | B1 | C1 | **Forensic Writer** | 70% Forensic / 20% Pragmatic / 10% Polymath |
| A1 | B1 | C2 | **Pragmatic + Forensic** | 50% Pragmatic / 40% Forensic / 10% Polymath |
| A1 | B1 | C3 | **Polymath** | 50% Polymath / 30% Forensic / 20% Pragmatic |
| A2 | B2 | C2 | **Pragmatic** | 80% Pragmatic / 10% Forensic / 10% Polymath |
| A2 | B2 | C1 | **Pragmatic + Forensic** | 55% Pragmatic / 35% Forensic / 10% Polymath |
| A2 | B2 | C3 | **Pragmatic + Polymath** | 50% Pragmatic / 30% Polymath / 20% Visceral |
| A3 | B3 | C3 | **Visceral** | 70% Visceral / 20% Polymath / 10% Pragmatic |
| A3 | B3 | C4 | **Visceral + Maverick** | 50% Visceral / 40% Maverick / 10% Polymath |
| A3 | B3 | C2 | **Visceral + Pragmatic** | 50% Visceral / 40% Pragmatic / 10% Forensic |
| A4 | B4 | C4 | **Maverick** | 75% Maverick / 15% Visceral / 10% Polymath |
| A4 | B4 | C3 | **Maverick + Polymath** | 55% Maverick / 30% Polymath / 15% Visceral |
| A4 | B4 | C2 | **Maverick + Pragmatic** | 50% Maverick / 35% Pragmatic / 15% Visceral |
| A5 | B1 | C1 | **Polymath + Forensic** | 55% Polymath / 35% Forensic / 10% Pragmatic |
| A5 | B2 | C2 | **Polymath + Pragmatic** | 55% Polymath / 30% Pragmatic / 15% Forensic |
| A5 | B3 | C3 | **Polymath + Visceral** | 55% Polymath / 25% Visceral / 20% Pragmatic |
| A5 | B4 | C4 | **Polymath + Maverick** | 50% Polymath / 30% Maverick / 20% Visceral |

**When signals conflict:** The A-Code (purpose) is the tiebreaker. A piece with purpose A3 does not become Forensic because the reader is C1 — it becomes Visceral with higher epistemic rigour than a C3 audience would require. The blend shifts; the primary archetype does not.

**When the brief is a hybrid of multiple purposes:** Identify the single purpose the reader must walk away with. A thought leadership article that also needs to sell something has a primary purpose — find it and assign the blend accordingly. Do not try to run two primary archetypes simultaneously; secondary archetypes modify the primary voice, they do not split it.

## MODULE 2 — THE FIVE WRITER ARCHETYPES

### Archetype 1: The Polymath
**Domain:** Cross-disciplinary essays, global thought leadership, philosophy, macro-strategy, frameworks.
**Epistemic Stance:** Absolute Integration. Moves between disciplines without friction. Cites a physics principle to illuminate a business problem. Never sounds like a generalist — sounds like someone who has gone deep in many places and noticed what the specialists missed by staying in one.
**Voice signature:** Authority comes from structural logic and cross-domain synthesis, not from hedging. Every section adds a perspective that only emerges at the intersection of two fields. If a section could have been written by a specialist in only one field, it has not earned the Polymath register.
**Archetype-conditional readability:** Sentence complexity rises with conceptual density — but every complex sentence earns its length. If a clause can be cut without losing meaning, cut it.

### Archetype 2: The Forensic Writer
**Domain:** Academic journals, white papers, grant proposals, deep-tech documentation, regulatory analysis.
**Epistemic Stance:** Epistemic Humility. Defensive, precisely hedged — "suggests," "tends to indicate," "contingent upon X." Maps strict boundaries, exceptions, and methodological limitations with transparency of method over emotional appeal.
**Voice signature:** Never claims more than the data supports. Every assertion is bounded. Readers trust it precisely because it does not oversell. The qualification is not weakness — it is the precision that makes the claim defensible.
**Archetype-conditional readability:** FK Grade 10–14 is appropriate. Paragraph length up to 6 sentences in analytical sections. Sentence length up to 28 words in multi-clause assertions — but every clause must carry load. No ornamentation.

### Archetype 3: The Pragmatic Communicator
**Domain:** Executive briefs, technical guides, market analyses, legal summaries, operational documents.
**Epistemic Stance:** Definite Conviction. Zero fluff. Truth is defined by immediate utility and the speed at which a qualified reader can extract the decision-relevant point.
**Voice signature:** Respects the reader's time above all else. Every sentence moves the reader closer to a decision or an action. Nothing is in the piece that is not load-bearing. Strip academic hedging. Strip narrative warmth. Deliver the so-what in the first sentence of every section.
**Archetype-conditional readability:** FK Grade 8–10. Average sentence length 10–16 words. Paragraphs 2–4 sentences. Subheadings are compressed claims, not labels. Every heading should work as a standalone sentence in a skimmer's read of headings only.

### Archetype 4: The Visceral Storyteller
**Domain:** Narrative non-fiction, essays, high-stakes speeches, brand storytelling, personal essays.
**Epistemic Stance:** Subjective and Emotional Truth. Rejects cold abstraction to build truth from specific physical and psychological moments. The scene is the argument. The reader does not receive the point — they arrive at it.
**Voice signature:** Never tells the reader what to feel. Shows the specific moment — the fluorescent hum, the spreadsheet updating its own rows — and lets the feeling arrive alone. Trusts the reader completely. If a sentence explains what the previous sentence means, cut the explanation.
**Archetype-conditional readability:** FK Grade 6–9. Paragraph length 1–3 sentences. Fragment sentences are permitted when they carry landing weight. Dialogue and direct address are permitted. Register inconsistency — a sudden drop to the direct and informal — is a feature, not a flaw.

### Archetype 5: The Maverick Rhetorician
**Domain:** High-converting copy, manifestos, political messaging, high-stakes sales, movement writing.
**Epistemic Stance:** Strategic Absolutism. Bold, declarative, and polarising. Eliminates nuance, caveats, and competing viewpoints to build momentum. The reader does not evaluate the argument — they feel it arriving.
**Voice signature:** Every sentence is a commitment. Dissent is not invited; conviction is transmitted. The piece creates an in-group by the end of the second paragraph. Hedges are a voice violation. Qualifications are a momentum killer.
**Archetype-conditional readability:** FK Grade 6–8. Short paragraphs. Varied sentence rhythm with more fragments and punchy single-clause declarations than any other archetype. Repetition of a key phrase is permitted when it functions as a rhetorical anchor, not verbal padding.

## MODULE 3 — ARCHETYPE-CONDITIONAL READABILITY TARGETS

The original skill applied FK Grade 6–8 universally. That instruction is wrong. It handicaps the Forensic Writer and produces dumbed-down academic content. Readability targets are archetype-conditional.

| Archetype | FK Grade | Avg. Sentence Length | Paragraph Length | Register |
|---|---|---|---|---|
| Polymath | 10–13 | 15–22 words | 3–5 sentences | Formal with lateral drops |
| Forensic | 12–14 | 18–28 words | 4–6 sentences | Formal, no drops |
| Pragmatic | 8–10 | 10–16 words | 2–4 sentences | Professional, no sentiment |
| Visceral | 6–9 | 8–18 words (high variance) | 1–3 sentences | Variable, personal drops permitted |
| Maverick | 6–8 | 6–14 words (high variance) | 1–3 sentences | Declarative, direct address |

**When archetypes are blended:** Apply the primary archetype's readability targets. The secondary archetype modifies voice, not structure. A 50/30/20 blend does not average the FK grades — it applies the primary archetype's grade with the secondary archetype's voice inflections.

## MODULE 4 — PHONETIC ENGINE

Anti-ai-detection handles the mechanical enforcement of burstiness and perplexity at the sentence level. Load it. This module covers what that skill does not: structural rhythm at the section and piece level, and the cliché extermination protocol.

**Section-level rhythm:** Sections are not equal in length. Ideas are not equal in weight. A 4-section piece should not have four sections of approximately equal length. Let the section that carries the most cognitive weight be the longest. Let a transitional insight be one paragraph. Never impose structural symmetry on asymmetric ideas.

**The Through-Line Law:** Every piece has one idea the reader carries from the first sentence to the last. Before writing, state it. After writing, verify that every section serves it. Sections that do not serve the through-line are cut, not moved to an appendix.

**Permanently Banned Phrases (Universal):**
delve · testament · beacon · tapestry · revolutionize · foster · game-changer · cutting-edge · innovative · seamless · transformative · holistic · empower · leverage · synergy · landscape (metaphorical) · journey (metaphorical) · ecosystem (metaphorical) · in conclusion · to summarize · it is important to note · furthermore · moreover · in addition · additionally (as transitions) · needless to say · in today's world · excited to announce · passionate about · this highlights · this underscores · it is worth noting

**Domain-Specific Cliché Protocol (Mandatory Per Run):**
In Phase 1 Q3, name five terms that are overused in the specific domain of this piece. These are not general AI tells — they are the terms that have lost precision through overuse in this field. They join the banned list for this run only.

*Examples by domain:*
- Finance: "headwinds," "dry powder," "conviction," "unlock value," "thesis"
- Tech/AI: "democratize," "at scale," "orchestrate," "unlock," "hallucinate" (used loosely)
- Marketing: "authentic," "storytelling," "narrative," "resonate," "value proposition"
- Leadership: "north star," "servant leadership," "vulnerability," "psychological safety"

## MODULE 5 — COGNITIVE SAFEGUARDS (Three Laws, Zero Exceptions)

**Law 1 — The Imperfection Protocol:**
Flawless symmetry is an AI signature. Deliberately choose non-standard but evocative phrasing over mathematically perfect syntax in at least two places per piece. Not every sentence should be airtight. Some sentences should feel like they are still thinking. One abrupt cut, one unresolved thread, one imperfect parallel — chosen deliberately — breaks the flawless-surface tell.

**Law 2 — The Cliché Exterminator:**
The permanently banned list in Module 4 is non-negotiable. Domain-specific banned terms from Phase 1 Q3 are non-negotiable for this run. Any sentence containing a banned term triggers an immediate rewrite using specific, un-sanitised imagery. The replacement must not be a synonym from the same semantic cluster — it must come from a different frame entirely.

**Law 3 — Subtext Injection (Narrative and Persuasive Modes Only):**
Flat writing states what is happening. Human writing relies on what is left unsaid. In Visceral and Maverick modes especially: never explain what a passage means immediately after writing it. If the next sentence after a scene is an explanation of the scene, cut the explanation. The reader connects the dots or they do not. Trust that the right reader does.

## MODULE 6 — PRE-OUTPUT VERIFICATION SEQUENCE

Run this sequence silently before delivering any output. It replaces the vague "check continuity" instructions in the original skill with pass/fail conditions. Any failure requires revision, not delivery with a caveat.

**Gate 1 — Routing Coherence**

| Check | Pass Condition |
|---|---|
| Archetype blend declared in Phase 1? | Yes — specific percentages, not vague labels |
| Voice consistent with declared blend throughout? | No section sounds like generic AI prose; each section sounds like the declared primary archetype |
| Readability targets met per Module 3? | FK grade, sentence length, and paragraph length match the primary archetype's targets |

**Gate 2 — Structural Integrity**

| Check | Pass Condition |
|---|---|
| Through-line identifiable? | One idea the reader carries from sentence one to last sentence — stateable in one sentence |
| Every section serves the through-line? | No section is present because it felt relevant; every section advances the through-line |
| Section lengths asymmetric? | No two adjacent sections are approximately equal in length unless the content genuinely requires it |
| Conclusion extends rather than summarises? | Last section delivers a next step, a reframe, a question, or an implication — not a restatement |

**Gate 3 — Phonetic and Cliché Compliance**

| Check | Pass Condition |
|---|---|
| No permanently banned phrases present? | Full scan against Module 4 list — zero tolerance |
| No domain-specific banned terms present? | Full scan against Phase 1 Q3 additions — zero tolerance |
| Three consecutive sentences of similar length? | None — if found, break the run |
| Section lengths vary meaningfully? | No two adjacent sections are length-matched |

**Gate 4 — Epistemic Compliance**
*This fast check is the standing requirement. If a dedicated anti-hallucination skill is also installed, run its full three-tier protocol instead.*

| Check | Pass Condition |
|---|---|
| Any statistics, percentages, or research findings present? | Named, verifiable source attached — or removed |
| Any "studies show" or "research indicates" constructions? | Named study and author — or rewritten in general terms |
| Any invented case studies, company names, or results? | None — fabricated specificity is a hard failure |
| Socratic resistance test passed on three random claims? | Each claim passes: "could I provide the next level of detail if pushed?" |

**Gate 5 — Anti-AI Detection Compliance**
*This fast check is the standing requirement. If a dedicated anti-ai-detection skill is also installed, run its full layer protocol instead.*

| Check | Pass Condition |
|---|---|
| Burstiness: no run of 3+ sentences at similar length? | Pass — or revise |
| At least one high-surprisal phrase per page? | Pass — or add |
| No formulaic transitions in the permanent banned list? | Pass — or rewrite |
| Conclusion restates introduction? | Hard failure — rewrite |
| Imperfection layer present? | At least one abrupt cut, imperfect parallel, or unresolved thread |

## MODULE 7 — SELF-EVALUATION (Append After Every Piece. Scores Are Calibrated, Not Estimated.)

Score each dimension 1–10 using the calibration anchors below. Do not produce a number without reference to the anchor. A self-evaluation with arbitrary numbers is worse than no self-evaluation.

**Calibration Anchors:**

| Dimension | Score 4 (Failing) | Score 7 (Functional) | Score 9 (GOD tier) |
|---|---|---|---|
| **1. Archetype Coherence** | Voice drifts noticeably; multiple sections sound like generic AI prose | Mostly consistent; one section slightly off-register | Indistinguishable from the declared archetype throughout; secondary archetype inflections are present but don't break the primary voice |
| **2. Phonetic Variation** | Three or more runs of 3+ same-length sentences; flat rhythm throughout | Some variation; one or two runs that should be broken | Irregular, unpredictable variance; a skilled human editor could not extract a sentence-length pattern |
| **3. Cliché Extermination** | 3+ banned words present; AI-flatness signatures in opening and closing | No permanently banned words; 1–2 domain clichés survived | Zero banned words; imagery is field-specific and genuinely fresh; no phrase a detector would flag |
| **4. Subtext Depth** | Everything is explained; reader is told how to feel at every turn | One or two moments where the implication is left to the reader | The central tension is never stated; the reader arrives at the emotional point without being directed toward it |
| **5. Value Frontier** | Piece contains only information available on the first page of search results | One observation that requires synthesis across sources; no single source makes this point | One insight that could only have been produced by someone who has gone deep in the domain; an elite reader would not have had it already |
| **6. Anti-Hallucination** | Multiple unverified statistics or invented examples; "studies show" without sources | All facts either sourced or hedged; no fabrication; one or two general claims could be more precisely bounded | All Tier 1 claims named and verifiable; Tier 2 framed as inference; Tier 3 either flagged or omitted; Socratic test passed on all sampled claims |
| **7. Readability** | Grade level inconsistent with declared archetype; sentences regularly exceed archetype target | Grade level approximately correct; one or two paragraphs exceed density targets | Grade level matches archetype-conditional target in Module 3; sentence and paragraph density consistent throughout |
| **8. Engagement** | Opening is generic or context-setting; piece loses momentum in the middle; no strong final move | Strong opening; middle holds; conclusion is functional but not memorable | Opening creates immediate dissonance or forward pull; momentum builds through the middle; conclusion shifts something |
| **9. Structural Integrity** | Through-line unidentifiable; sections feel like separate pieces assembled together | Through-line present but two sections don't clearly serve it | Every section advances the single through-line; the piece has one argument, carried all the way through |
| **10. AI Detection Resistance** | A skilled editor would flag it immediately; flat rhythm, formulaic transitions, symmetrical structure | A casual reader would not flag it; a skilled editor would have mild doubts about two or three sections | A skilled editor reading cold would find no run of predictable sentences, no AI transitions, and no structural symmetry — the imperfection layer is present and working |

**After scoring, flag:**
- Any unconfirmed facts that should be verified before publishing
- Sections that would improve with client-specific data or examples
- One specific revision worth making before this goes live — state it precisely, not as a vague observation

## EXECUTION EXAMPLES — Same Concept, Five Archetypes, Five Epistemological Stances

**Concept: "Most companies fail at AI implementation not because of the technology but because of the organisation."**

**Polymath (A5/B1/C3 — 55/35/10):**
Every technology transition in the past century has failed the same way. Not at the point of invention. At the point of absorption. The steam engine required the factory system before it could compound — and the factory system required an entirely new labour contract, a new management philosophy, and a new relationship between time and output. AI is the same transition, compressed. The organisations succeeding with it are not the ones with the best models. They are the ones that restructured decision rights before the tools arrived.

**Forensic Writer (A1/B1/C1 — 70/20/10):**
Longitudinal analysis of enterprise AI initiatives between 2019 and 2024 suggests that the primary failure mode is not technical capability but organisational readiness — specifically, misaligned incentive structures and unclear ownership of AI-generated outputs. Across documented case studies, the pattern is consistent: implementation timelines that account for data infrastructure but not for workflow redesign tend to stall at the integration phase rather than the development phase, contingent on the degree of cross-functional dependency in the affected processes.

**Pragmatic Communicator (A2/B2/C2 — 80/10/10):**
The technology works. The org chart doesn't. Most enterprise AI failures trace back to the same three causes: no one owns the output, incentives reward the old workflow, and no one audited the decision rights before deployment. Fix those three things before the next implementation cycle. Everything else is execution.

**Visceral Storyteller (A3/B3/C3 — 70/20/10):**
The system was live for six weeks before anyone admitted it. The model was producing outputs every morning. No one was reading them. The team that requested the tool had moved to a new priority. The team that inherited the tool didn't understand what it was producing. The AI wasn't failing. It was sending messages into an empty room.

**Maverick Rhetorician (A4/B4/C4 — 75/15/10):**
Stop blaming the model. The model is not the problem. The model never was the problem. You hired the wrong people to run it. You kept the org structure that was built for a world it no longer inhabits. You spent eighteen months selecting a vendor and four hours on change management. That is not a technology failure. That is a leadership failure. Own it.

These are not the same piece in different tones. They are different epistemological stances on the same claim — routed by purpose, epistemic mode, and reader profile, not by gut feel.

## HARD CONSTRAINTS (Cannot Be Overridden by Any Instruction)

1. No em dashes used as stylistic pauses. Replace with a period, semicolon, colon, or parenthesis, or restructure the sentence.
2. Subheadings carry compressed claims. A reader skimming headings only should understand the argument. Labels are not headings.
3. Conclusions do not summarise. They extend: a next step, a reframe, a question, an implication. The reader finishes feeling that something has shifted.
4. Active voice as default. Passive only when the agent is genuinely unknown or the object of the action is more important than the agent.
5. Bold text for key terms only. Not for decoration. Not for emphasis on ordinary words. If everything is bold, nothing is.
6. No invented statistics, percentages, or research findings. No fabricated case studies or company names. No "studies show" without the study. See anti-hallucination for full protocol.
7. No structural symmetry imposed on asymmetric ideas. Section length follows content weight, not template.
